## Chapter 69: EWMA and CUSUM: Detecting Small Shifts
### The engineering question

*How long are we willing to run off-target before the chart warns us?*

The Shewhart chart is excellent at detecting large shifts and poor at detecting small ones. This isn't a flaw: it's a direct consequence of each point being evaluated in isolation, with no memory of the past.

If the process shifts by 1σ, the probability that a single point falls outside the 3σ limits is only 2.3%. On average, it'll take **44 points** to detect it. If each point is an hourly sample, the shift survives almost two days.

### ARL: the right metric for comparing charts

**ARL (*Average Run Length*)** is the average number of points until a signal.

- **ARL₀** — with the process in control. It's the inverse of the false-alarm rate. We want it **large** (370 for a Shewhart 3σ chart).
- **ARL₁** — with the process shifted by δ sigmas. We want it **small**.

Every comparison between charts should be made **at equal ARL₀**. Comparing a chart with ARL₀ = 370 against another with ARL₀ = 100 and concluding the second one detects faster is trivially true and completely useless.

| Shift | Shewhart ARL₁ | EWMA ARL₁ (λ=0.2) | CUSUM ARL₁ (k=0.5, h=5) |
|---|---|---|---|
| 0.5σ | ~155 | ~26 | ~28 |
| 1.0σ | ~44 | ~10 | ~10 |
| 1.5σ | ~15 | ~6 | ~6 |
| 2.0σ | ~6.3 | ~4.5 | ~4.2 |
| 3.0σ | ~2.0 | ~2.9 | ~2.5 |

**Reading this table is the whole substance of this chapter:** for shifts up to ~2σ, EWMA and CUSUM detect 3 to 5 times faster. For large shifts (≥3σ), Shewhart is better. Hence the practical recommendation: **run a Shewhart chart and an EWMA/CUSUM in parallel**, each in the regime it's good at.

### EWMA

$$z_i = \lambda x_i + (1 - \lambda) z_{i-1}, \qquad z_0 = \mu_0$$

$$LC_i = \mu_0 \pm L\,\sigma \sqrt{\frac{\lambda}{2-\lambda}\left[1 - (1-\lambda)^{2i}\right]}$$

Each point is a weighted average of the whole history, with weights that decay geometrically. The parameter $\lambda$ controls the memory:

- Small $\lambda$ (0.05–0.10): lots of memory, great for very small shifts, slow for large ones.
- Medium $\lambda$ (0.20): the usual compromise.
- $\lambda \to 1$: EWMA collapses into the individuals chart.

The term in brackets makes the limits **widen at the first points** and then stabilize — it's the fast initial response effect, which shouldn't be ignored.

### Tabular CUSUM

$$C_i^+ = \max\left[0,\; x_i - (\mu_0 + k\sigma) + C_{i-1}^+\right] \qquad C_i^- = \max\left[0,\; (\mu_0 - k\sigma) - x_i + C_{i-1}^-\right]$$

Signal when $C^+ > h\sigma$ or $C^- > h\sigma$.

- $k$ is the **slack**, typically half the shift you want to detect: to detect 1σ, $k = 0.5$.
- $h$ is the **decision limit**, typically 4 or 5. With $k=0.5$ and $h=5$, you get ARL₀ ≈ 465.

CUSUM has a property EWMA doesn't: the chart's **slope** after the signal lets you estimate the shift's magnitude, and the point where $C^+$ left zero estimates **when** the shift began. This is very valuable diagnostic information for cause analysis.

### Worked example: all three charts on the same process

```py-r
--- python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
mu0, sigma = 100.0, 2.0
n_antes, n_depois, desloc = 50, 50, 0.75      # deslocamento de 0,75 sigma

x = np.concatenate([rng.normal(mu0, sigma, n_antes),
                    rng.normal(mu0 + desloc*sigma, sigma, n_depois)])
inicio_real = n_antes

# ---------- 1. Shewhart individuais ----------
lsc_s, lic_s = mu0 + 3*sigma, mu0 - 3*sigma
sinal_s = np.where((x > lsc_s) | (x < lic_s))[0]

# ---------- 2. EWMA ----------
lam, L = 0.20, 2.962           # L=2.962 dá ARL0 ~ 370 para lambda=0.2
z = np.zeros(len(x)); prev = mu0
for i, xi in enumerate(x):
    prev = lam*xi + (1-lam)*prev; z[i] = prev
i_idx = np.arange(1, len(x)+1)
half = L*sigma*np.sqrt(lam/(2-lam)*(1-(1-lam)**(2*i_idx)))
lsc_e, lic_e = mu0 + half, mu0 - half
sinal_e = np.where((z > lsc_e) | (z < lic_e))[0]

# ---------- 3. CUSUM ----------
k, h = 0.5, 5.0
Cp = np.zeros(len(x)); Cm = np.zeros(len(x))
for i, xi in enumerate(x):
    p = Cp[i-1] if i else 0.0; m = Cm[i-1] if i else 0.0
    Cp[i] = max(0, xi - (mu0 + k*sigma) + p)
    Cm[i] = max(0, (mu0 - k*sigma) - xi + m)
sinal_c = np.where((Cp > h*sigma) | (Cm > h*sigma))[0]

def primeiro(sinais):
    apos = [s for s in sinais if s >= inicio_real]
    return (apos[0], apos[0] - inicio_real) if apos else (None, None)

print(f"Deslocamento de {desloc}σ introduzido no ponto {inicio_real}\n")
res = []
for nome, sig, fa in [("Shewhart 3σ", sinal_s, sinal_s[sinal_s < inicio_real]),
                      ("EWMA λ=0,20", sinal_e, sinal_e[sinal_e < inicio_real]),
                      ("CUSUM k=0,5 h=5", sinal_c, sinal_c[sinal_c < inicio_real])]:
    p, atraso = primeiro(sig)
    res.append({"Carta": nome,
                "1º sinal após a mudança": p if p is not None else "NÃO DETETOU",
                "Atraso (pontos)": atraso if atraso is not None else "-",
                "Falsos alarmes antes": len(fa)})
print(pd.DataFrame(res).to_string(index=False))

# Diagnóstico da CUSUM: quando começou?
if len(sinal_c):
    s = sinal_c[0]
    j = s
    while j > 0 and Cp[j-1] > 0: j -= 1
    print(f"\nDiagnóstico CUSUM: o acumulador saiu de zero no ponto {j} "
          f"(mudança real no ponto {inicio_real}).")
    print(f"Magnitude estimada do deslocamento: {Cp[s]/(s-j+1)/sigma + k:.2f}σ "
          f"(real: {desloc}σ)")

fig, axes = plt.subplots(3, 1, figsize=(11, 9), sharex=True)
axes[0].plot(x, "o-", ms=3, lw=0.8, color="#00688f")
axes[0].axhline(lsc_s, color="r", ls="--"); axes[0].axhline(lic_s, color="r", ls="--")
axes[0].axhline(mu0, color="g"); axes[0].set_title("Shewhart (individuais)")
axes[1].plot(z, "o-", ms=3, lw=0.8, color="#6a3d9a")
axes[1].plot(lsc_e, "r--"); axes[1].plot(lic_e, "r--"); axes[1].axhline(mu0, color="g")
axes[1].set_title("EWMA (λ = 0,20)")
axes[2].plot(Cp, "o-", ms=3, lw=0.8, label="C+", color="#d17a00")
axes[2].plot(Cm, "o-", ms=3, lw=0.8, label="C−", color="#31803a")
axes[2].axhline(h*sigma, color="r", ls="--"); axes[2].legend()
axes[2].set_title("CUSUM tabular (k = 0,5 ; h = 5)")
for ax in axes:
    ax.axvline(inicio_real, color="black", ls=":", lw=1.5)
    ax.text(inicio_real+0.5, ax.get_ylim()[1]*0.98, " mudança real",
            fontsize=8, va="top")
axes[2].set_xlabel("observação")
plt.tight_layout(); plt.show()
```

### Verifying ARL by simulation

Don't accept table ARL values without checking them for your own parameters. It's cheap to simulate.

```py-r
--- python
import numpy as np

def arl_ewma(desloc, lam=0.2, L=2.962, sigma=1.0, n_sim=3000, max_n=3000, seed=1):
    rng = np.random.default_rng(seed); runs = []
    for _ in range(n_sim):
        prev, i = 0.0, 0
        while i < max_n:
            i += 1
            prev = lam*rng.normal(desloc, sigma) + (1-lam)*prev
            lim = L*sigma*np.sqrt(lam/(2-lam)*(1-(1-lam)**(2*i)))
            if abs(prev) > lim: break
        runs.append(i)
    return np.mean(runs)

def arl_cusum(desloc, k=0.5, h=5.0, sigma=1.0, n_sim=3000, max_n=3000, seed=1):
    rng = np.random.default_rng(seed); runs = []
    for _ in range(n_sim):
        Cp = Cm = 0.0; i = 0
        while i < max_n:
            i += 1; x = rng.normal(desloc, sigma)
            Cp = max(0, x - k*sigma + Cp); Cm = max(0, -k*sigma - x + Cm)
            if Cp > h*sigma or Cm > h*sigma: break
        runs.append(i)
    return np.mean(runs)

def arl_shewhart(desloc):
    from scipy import stats
    p = stats.norm.sf(3 - desloc) + stats.norm.cdf(-3 - desloc)
    return 1/p

print(f"{'Deslocamento':>13} | {'Shewhart':>9} | {'EWMA':>8} | {'CUSUM':>8}")
print("-"*48)
for d in [0.0, 0.5, 1.0, 1.5, 2.0, 3.0]:
    print(f"{d:>11.1f}σ | {arl_shewhart(d):>9.0f} | "
          f"{arl_ewma(d):>8.0f} | {arl_cusum(d):>8.0f}")
print("\n(a primeira linha é o ARL0 — as três cartas devem ter ARL0 comparável"
      "\n para que a comparação das restantes linhas seja legítima)")
```

### Western Electric Rules ↔ Nelson Rules

The "Nelson rules" cited in Common mistakes above are not a system independent from the older
zone rules. Lloyd S. Nelson published his set of eight rules in the *Journal of Quality
Technology* in 1984 — and seven of the eight come directly from the *Western Electric
Statistical Quality Control Handbook* (1956), the manual that first codified the zone rules
(1σ/2σ/3σ) used in industrial SPC. Nelson didn't replace the earlier system: he rebalanced the
false-alarm probability of each rule (to make them more uniform with each other) and added new
rules, mainly to detect trends and stratification patterns that the original 1956 set didn't
cover.

| Origin | Rule (summary) | In Nelson's set |
|---|---|---|
| Western Electric (1956) | 1 point beyond 3σ | Rule 1 |
| Western Electric (1956) | 2 of 3 consecutive points beyond 2σ, same side | Rule 5 |
| Western Electric (1956) | 4 of 5 consecutive points beyond 1σ, same side | Rule 6 |
| Western Electric (1956) | 8 consecutive points on the same side of the centerline | Rule 2 |
| Nelson (1984), addition | 6 consecutive points trending up or down | Rule 3 |
| Nelson (1984), addition | 14 points alternating up/down | Rule 4 |
| Nelson (1984), addition | 15 consecutive points within 1σ (stratification/suppressed variation) | Rule 7 |
| Nelson (1984), addition | 8 consecutive points outside 1σ, both sides | Rule 8 |

In practice, when the code of an SPC system (like `apply_western_electric_rules` in the
*manufacturing-performance-analytics* project) implements "the Western Electric rules," it is
implementing a subset of the four original 1956 zone rules — typically Rules 1, 2, 5, and 6 from
the list above. This isn't a different system from what this chapter already discusses as
"Nelson rules" — it's the historical core of the same system, under its older name.

### ARL When Rules Are Combined: No Closed-Form Formula

The `arl_shewhart`, `arl_ewma`, and `arl_cusum` functions above compute the ARL of a **single
decision rule** per chart — one limit exceeded, one EWMA out of bounds, one CUSUM that crosses h.
For that case, `arl_shewhart` even has a closed-form formula (ARL₀ = 1/α).

That stops holding once **several sequence rules run simultaneously** on the same chart —
exactly the case of a system that applies the four (or eight) zone rules at the same time, as in
the table above. Each rule, on its own, has a certain probability of a chance signal; combined,
the probabilities don't add up simply because the events aren't independent (several rules can
fire at the same point, or violating one rule makes another more likely at the next point). There
is no closed-form formula for the ARL₀ of a combined rule set — the only practical way to
estimate it is by **Monte Carlo simulation**: generate many long in-control series, apply the
full rule set to each series, and count the empirical firing rate. That is exactly the exercise —
applied to the case of combined rules — that Chapter 140 develops in detail.

### Common mistakes

1. **Comparing charts without equalizing ARL₀.** This is the dominant methodological error in this subject.
2. **Applying the Nelson rules to an EWMA.** EWMA's points are strongly autocorrelated by construction; sequence rules don't carry the same meaning they would on a Shewhart chart and trigger false alarms.
3. **Using EWMA/CUSUM as the only chart.** You lose sensitivity to large shifts and isolated spikes. Run both.
4. **Choosing λ or k without defining the target shift.** These are design parameters: first decide which shift carries economic consequence, then tune.
5. **Applying it to autocorrelated data.** EWMA and CUSUM assume independence, just like Shewhart. With autocorrelation, both produce cascading false alarms — see the next chapter.
