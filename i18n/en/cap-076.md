## Chapter 76: Randomization, Blocking, Replicates, and Center Points ✦

### The engineering question

*What can ruin this trial, and what do I do about each of those threats?*

Fisher formulated the three principles of experimental design, and each answers a distinct threat. They aren't interchangeable.

| Principle | Threat it neutralizes | What happens if it's missing |
|---|---|---|
| **Randomization** | Unknown factors correlated with order | The estimated effect includes the unknown factor's. Bias. |
| **Replicates** | Not knowing how much is noise | No independent error estimate; no test is possible |
| **Blocking** | Known, inconvenient factors (lot, day, operator) | The block's variation enters the error and masks the effects |

**The mnemonic rule that sums it all up:**

> **Block what you can control. Randomize what you can't.**

### Blocking: sacrifice what matters least

If a $2^4$ trial (16 runs) doesn't fit in a single raw-material lot of 8 units, you run it in 2 blocks. But the blocks aren't formed at random: you **deliberately choose which effect gets confounded with the block**.

Using the block generator $ABCD$: runs with $ABCD = +1$ form block 1, those with $-1$ form block 2. The block effect gets confounded with the 4-factor interaction — the least interesting effect, and almost certainly negligible. Every main effect and every 2-factor interaction stays **clean**.

**Confounding with the block is a decision, and that's why it's good.** What's bad is confounding by accident — which is what happens when you run "the first 8 today and the other 8 tomorrow" with no structure.

### Center points: cheap insurance

Adding 3 to 5 runs at the center conditions of every factor gives you **two things for the price of one**:

1. **A pure estimate of experimental error**, with its own degrees of freedom, even in an unreplicated design.
2. **A curvature test**: if the center points' average differs significantly from the factorial points' average, there's curvature a 2-level model can't represent.

$$SS_{curvature} = \frac{n_F \, n_C \,(\bar{y}_F - \bar{y}_C)^2}{n_F + n_C}$$

**The practical consequence is huge.** If there's curvature and the linear model ignores it, optimization points to the edge of the domain, when the real optimum might be in the middle. A trial that detects curvature says immediately: *"stop, it's time to move to response surface"* (next chapter).

### Worked example

```py-r
--- python
import numpy as np
import pandas as pd
from itertools import product
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(1234)

# --- Desenho 2^4 + 4 pontos centrais, em 2 blocos confundidos com ABCD ---
fat = pd.DataFrame(list(product([-1,1], repeat=4)), columns=list("ABCD"))
fat["Bloco"] = np.where(fat.A*fat.B*fat.C*fat.D == 1, 1, 2)
centrais = pd.DataFrame({"A":[0]*6, "B":[0]*6, "C":[0]*6, "D":[0]*6,
                         "Bloco":[1,1,1,2,2,2]})
des = pd.concat([fat, centrais], ignore_index=True)

# Ordem aleatória DENTRO de cada bloco
des["Ordem"] = 0
for b in [1, 2]:
    idx = des.index[des.Bloco == b]
    des.loc[idx, "Ordem"] = rng.permutation(len(idx)) + 1

# --- Verdade: efeitos A e C, interação AC, CURVATURA, e um efeito de bloco ---
efeito_bloco = {1: -1.8, 2: +1.8}
des["Y"] = (70.0 + 3.2*des.A + 2.0*des.C + 1.6*des.A*des.C
            - 2.6*(des[["A","B","C","D"]].abs().sum(axis=1) == 0).astype(float)*0
            + des.Bloco.map(efeito_bloco)
            + rng.normal(0, 0.55, len(des)))
# curvatura: os pontos centrais ficam ACIMA da média fatorial
des.loc[des.A.abs()+des.B.abs()+des.C.abs()+des.D.abs() == 0, "Y"] += 3.4

print(f"Desenho: {len(fat)} corridas fatoriais + {len(centrais)} pontos centrais "
      f"em {des.Bloco.nunique()} blocos\n")
print(des.sort_values(["Bloco","Ordem"]).head(10).to_string(index=False))

fatoriais = des[des[["A","B","C","D"]].abs().sum(axis=1) > 0]
cent = des[des[["A","B","C","D"]].abs().sum(axis=1) == 0]

# --- 1. Teste de curvatura ---
yF, yC = fatoriais.Y.mean(), cent.Y.mean()
nF, nC = len(fatoriais), len(cent)
s2_puro = cent.Y.var(ddof=1)
SS_curv = nF*nC*(yF - yC)**2/(nF + nC)
F_curv = SS_curv/s2_puro
p_curv = 1 - stats.f.cdf(F_curv, 1, nC-1)
print(f"\n1) TESTE DE CURVATURA")
print(f"   Média dos pontos fatoriais = {yF:.3f}")
print(f"   Média dos pontos centrais  = {yC:.3f}   (diferença = {yC-yF:+.3f})")
print(f"   Erro puro (dos centrais): s² = {s2_puro:.4f}  com {nC-1} g.l.")
print(f"   F = {F_curv:.2f}, p = {p_curv:.4f}")
print(f"   => {'CURVATURA SIGNIFICATIVA — o modelo de 2 níveis é insuficiente' if p_curv < 0.05 else 'sem curvatura detetável'}")

# --- 2. Efeito do bloco ---
print(f"\n2) EFEITO DO BLOCO")
b1, b2 = des[des.Bloco==1].Y.mean(), des[des.Bloco==2].Y.mean()
print(f"   Média bloco 1 = {b1:.3f} | bloco 2 = {b2:.3f} | diferença = {b2-b1:+.3f}")
print(f"   Este efeito está confundido com ABCD (por construção) e é removido")
print(f"   da estimativa dos restantes efeitos.")

# --- 3. Efeitos, com e sem blocagem ---
def efeitos(df, blocado):
    dd = df.copy()
    if blocado:                       # centrar Y dentro de cada bloco
        dd["Y"] = dd.groupby("Bloco")["Y"].transform(lambda s: s - s.mean() + dd.Y.mean())
    out = {}
    for f in "ABCD":
        out[f] = dd.loc[dd[f]==1,"Y"].mean() - dd.loc[dd[f]==-1,"Y"].mean()
    for f1, f2 in [("A","B"),("A","C"),("A","D"),("B","C"),("B","D"),("C","D")]:
        col = dd[f1]*dd[f2]
        out[f1+f2] = dd.loc[col==1,"Y"].mean() - dd.loc[col==-1,"Y"].mean()
    return pd.Series(out)

sem_b = efeitos(fatoriais, blocado=False)
com_b = efeitos(fatoriais, blocado=True)
se_ef = 2*np.sqrt(s2_puro/nF)
t_crit = stats.t.ppf(0.975, nC-1)
comp = pd.DataFrame({"Sem blocagem": sem_b.round(3), "Com blocagem": com_b.round(3)})
comp["|Δ|"] = (sem_b - com_b).abs().round(3)
comp["Significativo"] = np.where(com_b.abs() > t_crit*se_ef, "SIM", "")
print(f"\n3) EFEITOS ESTIMADOS  (erro-padrão do efeito = {se_ef:.3f}, "
      f"limite = {t_crit*se_ef:.3f})")
print(comp.sort_values("Com blocagem", key=np.abs, ascending=False).to_string())

# --- 4. O custo de não aleatorizar ---
print(f"\n4) O QUE ACONTECE SE NÃO ALEATORIZARMOS")
des_ord = des.sort_values(["A","B","C","D"]).reset_index(drop=True)
deriva = np.linspace(0, 4.0, len(des_ord))            # ex.: aquecimento da máquina
des_ord["Y_deriva"] = des_ord.Y + deriva
fat_ord = des_ord[des_ord[["A","B","C","D"]].abs().sum(axis=1) > 0]
ef_viciado = (fat_ord.loc[fat_ord.A==1,"Y_deriva"].mean()
              - fat_ord.loc[fat_ord.A==-1,"Y_deriva"].mean())
print(f"   Corridas por ordem sistemática, com deriva térmica de +4 ao longo do ensaio:")
print(f"   Efeito real de A          = {com_b['A']:.3f}")
print(f"   Efeito estimado com deriva = {ef_viciado:.3f}  "
      f"(erro de {ef_viciado-com_b['A']:+.3f})")
print(f"   => a deriva foi inteiramente atribuída ao fator A.")

fig, axes = plt.subplots(1, 2, figsize=(13, 4))
axes[0].scatter(range(nF), fatoriais.Y, label="fatoriais", s=30)
axes[0].scatter(range(nF, nF+nC), cent.Y, color="red", s=60, label="centrais")
axes[0].axhline(yF, ls="--", label=f"média fatorial = {yF:.2f}")
axes[0].axhline(yC, color="red", ls="--", label=f"média central = {yC:.2f}")
axes[0].legend(fontsize=8); axes[0].set_title("Pontos centrais revelam a curvatura")
e = com_b.sort_values(key=np.abs, ascending=True)
axes[1].barh(range(len(e)), e.values,
             color=["#a5203a" if abs(v) > t_crit*se_ef else "#93a7ae" for v in e.values])
axes[1].set_yticks(range(len(e))); axes[1].set_yticklabels(e.index, fontsize=8)
axes[1].axvline(t_crit*se_ef, color="r", ls="--"); axes[1].axvline(-t_crit*se_ef, color="r", ls="--")
axes[1].set_title("Efeitos com blocagem (linhas = limite de significância)")
plt.tight_layout(); plt.show()
```

**Engineering reading.** Three results, three lessons.

**The center points detected the curvature.** Four extra runs turned a trial that would've produced a misleading linear model into one that says clearly: *you need to move to response surface*. Cost: 4 runs out of 20.

**Blocking removed a systematic difference between lots.** Without it, that variation would have gone into the error and reduced the ability to detect the real effects.

**Systematic order attributed the thermal drift to factor A.** The estimated effect ended up grossly wrong — and nothing in the data would give it away. This is the definitive argument for randomization, and it's the principle most often sacrificed for operational convenience.

### When You Can't Randomize

Sometimes randomization is genuinely impractical: changing an oven's temperature takes 4 hours, changing the raw-material lot means cleaning the entire line. Making 16 random temperature changes might not be feasible.

**The right answer isn't to pretend you randomized.** It's to acknowledge the constraint and use the design that accommodates it: the **split-plot** design, where the hard-to-change factor varies slowly and the easy ones are randomized within each level. Split-plot has **two distinct experimental errors**, and analyzing it as a full factorial produces wrong tests — typically too optimistic for the hard-to-change factor and too conservative for the easy ones. That's the topic of one of the following chapters.

```py-r
' Dados > Analise de Dados > Anova: Fator Duplo Com Repeticao

```

The limitation to note: this tool assumes a **balanced** design (the same number of observations in each block × treatment combination). Unbalanced designs, incomplete blocks, or the correct error decomposition in designs with center points (as in the worked example, which combines blocking with center points) need the Python/R treatment already shown above — Excel works well as a quick first check, not as the final tool for a design with this much complexity.

### Common mistakes

1. **Randomizing only the analysis, not the execution.** The run order is what counts.
2. **Blocks formed for convenience.** "The 8 on Monday and the 8 on Tuesday" confounds the block with whatever changed between the days, and probably with main effects.
3. **Confusing replicates with repeated measurements.** Measuring the same part 3 times estimates **measurement** error; rerunning the run 3 times estimates **experimental** error. Only the second is suitable for testing effects — and using the first produces scandalously optimistic tests.
4. **Omitting center points to save runs.** It's the worst cost-benefit savings in all of DOE.
5. **Ignoring detected curvature.** If the test is significant, the linear model doesn't describe the process. Don't optimize with it.
