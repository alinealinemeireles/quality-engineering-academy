## Chapter 56: Multivariate Analysis: PCA and Hotelling's T² Control ✦

### The engineering question

*I have 15 control charts, all within limits. Is the process under control?*

Not necessarily. And the problem has two sides.

**Side 1 — the false-alarm rate multiplies.** With 15 independent charts at 3σ, the probability of at least one false alarm per period is $1 - (1-0{.}0027)^{15} \approx 4{.}0\,\%$, fifteen times the nominal rate. The team chases ghosts.

**Side 2 — and this is the more serious one — individual charts are blind to correlation.** Two variables can both be within their individual limits while the **combination** is impossible for a normal process. If temperature and pressure always move together, observing high temperature with low pressure is a serious anomaly that neither chart detects.

### Hotelling's T² statistic

$$T^2 = (\mathbf{x} - \bar{\mathbf{x}})' \mathbf{S}^{-1} (\mathbf{x} - \bar{\mathbf{x}})$$

It's the squared Mahalanobis distance: a distance that **accounts for the correlation structure**. Control regions go from rectangles (individual charts) to **ellipses** oriented along the correlation.

**Control limit (Phase II, monitoring with parameters estimated from $m$ subgroups):**

$$UCL = \frac{p(m+1)(n-1)}{mn - m - p + 1} F_{\alpha; \, p, \, mn-m-p+1}$$

**T²'s problem: it tells you *that* something is wrong, not *what*.** The answer is the **MYT decomposition**, which assigns each variable its contribution to the T² value — and that's what makes the chart actionable.

### PCA: when there are many redundant variables

With 30 strongly correlated sensors, the $\mathbf{S}$ matrix becomes ill-conditioned and inversion unstable. Principal component analysis solves this by projecting into a lower-dimensional space:

$$\mathbf{T} = \mathbf{X}\mathbf{P}$$

You then monitor **two** complementary statistics, and both are needed:

- **T² over the retained components** — detects variation *abnormal in magnitude* within the model. "The process moved too far along the axes we know."
- **SPE (*Squared Prediction Error*, or the Q statistic)** — detects variation *outside* the model. "Something happened that the model never saw."

The second is often the more valuable one: a broken sensor, new raw material, or an unprecedented failure mode shows up in the SPE, not the T².

> **Rule:** use PCA to reduce dimension whenever $p$ is large or the variables are highly correlated. Monitor **T² and SPE together** — one alone isn't enough.

### Worked example: 6 correlated process variables

```py-r
--- python
import numpy as np
import pandas as pd
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(555)

variaveis = ["temp_zona1", "temp_zona2", "pressao", "caudal", "rpm", "torque"]
p = len(variaveis)
m_fase1 = 200

# Estrutura de correlação realista
media = np.array([210.0, 205.0, 4.20, 88.0, 1450.0, 32.0])
sd = np.array([3.0, 3.2, 0.15, 2.5, 25.0, 1.8])
corr = np.array([
    [1.00, 0.88, 0.55, 0.20, 0.10, 0.15],
    [0.88, 1.00, 0.50, 0.18, 0.08, 0.12],
    [0.55, 0.50, 1.00, 0.65, 0.15, 0.25],
    [0.20, 0.18, 0.65, 1.00, 0.30, 0.35],
    [0.10, 0.08, 0.15, 0.30, 1.00, 0.75],
    [0.15, 0.12, 0.25, 0.35, 0.75, 1.00]])
cov = np.outer(sd, sd) * corr

fase1 = rng.multivariate_normal(media, cov, m_fase1)

# Fase 2: 60 observações normais, depois 3 anomalias de tipos diferentes
fase2 = rng.multivariate_normal(media, cov, 60)
anom = []
# a) quebra de correlação: temp_zona1 sobe, temp_zona2 desce (ambas DENTRO dos limites individuais)
x = media.copy(); x[0] += 2.2*sd[0]; x[1] -= 2.2*sd[1]; anom.append(x)
# b) deslocamento moderado de várias variáveis ao mesmo tempo
x = media + 1.6*sd; anom.append(x)
# c) uma variável muito fora
x = media.copy(); x[4] += 4.0*sd[4]; anom.append(x)
fase2 = np.vstack([fase2, np.array(anom)])

xbar = fase1.mean(axis=0); S = np.cov(fase1, rowvar=False); Sinv = np.linalg.inv(S)

def T2(X):
    dif = X - xbar
    return np.einsum("ij,jk,ik->i", dif, Sinv, dif)

t2 = T2(fase2)
n = 1
ucl = (p*(m_fase1+1)*(n-1) / (m_fase1*n - m_fase1 - p + 1)) * \
      stats.f.ppf(0.9973, p, m_fase1*n - m_fase1 - p + 1) if n > 1 else \
      (p*(m_fase1+1)*(m_fase1-1)/(m_fase1*(m_fase1-p))) * \
      stats.f.ppf(0.9973, p, m_fase1-p)

print(f"Fase I: {m_fase1} observações, {p} variáveis")
print(f"UCL do T² (alfa = 0,0027) = {ucl:.2f}\n")

# ---------- Comparar com cartas individuais ----------
lim_sup = xbar + 3*np.sqrt(np.diag(S)); lim_inf = xbar - 3*np.sqrt(np.diag(S))
print("AS TRÊS ANOMALIAS — o que cada abordagem deteta:")
nomes = ["a) quebra de correlação (temp1↑, temp2↓)",
         "b) deslocamento conjunto moderado (+1,6σ em todas)",
         "c) uma variável muito fora (rpm +4σ)"]
for i, nome in enumerate(nomes):
    obs = fase2[-3+i]
    idx = len(fase2)-3+i
    fora_ind = [variaveis[j] for j in range(p)
                if obs[j] > lim_sup[j] or obs[j] < lim_inf[j]]
    print(f"\n{nome}")
    print(f"   Cartas individuais 3σ : {'detetam ' + ', '.join(fora_ind) if fora_ind else 'NÃO DETETAM NADA'}")
    print(f"   T² de Hotelling       : T² = {t2[idx]:7.2f} "
          f"{'-> SINAL' if t2[idx] > ucl else '-> sem sinal'}")

# ---------- Decomposição MYT: qual variável contribui? ----------
print("\n\nDECOMPOSIÇÃO — contribuição de cada variável (anomalia 'a')")
obs = fase2[-3]
contrib = []
for j in range(p):
    resto = [k for k in range(p) if k != j]
    Sr = S[np.ix_(resto, resto)]; dr = (obs - xbar)[resto]
    t2_sem = dr @ np.linalg.inv(Sr) @ dr
    contrib.append({"Variável": variaveis[j],
                    "Valor": round(obs[j], 3),
                    "Z individual": round((obs[j]-xbar[j])/np.sqrt(S[j,j]), 2),
                    "T² sem esta var.": round(t2_sem, 2),
                    "Contribuição": round(t2[-3] - t2_sem, 2)})
cdf = pd.DataFrame(contrib).sort_values("Contribuição", ascending=False)
print(cdf.to_string(index=False))
print("\n=> Nenhum Z individual ultrapassa 3, mas temp_zona1 e temp_zona2")
print("   dominam o T²: a ANOMALIA ESTÁ NA RELAÇÃO entre elas, não nos níveis.")

# ---------- PCA e SPE ----------
Z = (fase1 - xbar) / fase1.std(axis=0, ddof=1)
Corr = np.cov(Z, rowvar=False)          # 'Corr' e não 'C': 'C' é reservado
vals, vecs = np.linalg.eigh(Corr)   # pelas fórmulas do statsmodels/patsy
ordem = np.argsort(vals)[::-1]; vals, vecs = vals[ordem], vecs[:, ordem]
var_exp = vals / vals.sum()
k = int(np.searchsorted(np.cumsum(var_exp), 0.90) + 1)
print(f"\n\nPCA: {k} componentes explicam {np.cumsum(var_exp)[k-1]:.1%} da variância")
print("   " + " | ".join(f"CP{i+1}: {v:.1%}" for i, v in enumerate(var_exp[:4])))

P = vecs[:, :k]
Zf2 = (fase2 - xbar) / fase1.std(axis=0, ddof=1)
Tsc = Zf2 @ P
recon = Tsc @ P.T
spe = ((Zf2 - recon)**2).sum(axis=1)
spe_lim = np.percentile(((Z - (Z @ P) @ P.T)**2).sum(axis=1), 99.73)
t2_pca = (Tsc**2 / vals[:k]).sum(axis=1)
t2_pca_lim = np.percentile((( (Z @ P)**2 / vals[:k]).sum(axis=1)), 99.73)

print(f"\n   Limites: T²(PCA) = {t2_pca_lim:.2f} | SPE = {spe_lim:.3f}")
for i, nome in enumerate(["a", "b", "c"]):
    idx = len(fase2)-3+i
    print(f"   Anomalia {nome}: T²(PCA) = {t2_pca[idx]:7.2f} "
          f"{'SINAL' if t2_pca[idx] > t2_pca_lim else '  -  '}"
          f" | SPE = {spe[idx]:7.3f} "
          f"{'SINAL' if spe[idx] > spe_lim else '  -  '}")

fig, axes = plt.subplots(2, 2, figsize=(13, 8))
axes[0,0].plot(t2, lw=0.9, marker="o", ms=3)
axes[0,0].axhline(ucl, color="r", ls="--")
axes[0,0].plot(range(len(t2)-3, len(t2)), t2[-3:], "ro", ms=8)
axes[0,0].set_yscale("log"); axes[0,0].set_title("Carta T² de Hotelling")
axes[0,1].scatter(fase1[:,0], fase1[:,1], s=8, alpha=0.4, label="Fase I")
axes[0,1].scatter(fase2[-3,0], fase2[-3,1], color="red", s=90, marker="X",
                  label="anomalia (a)")
for v, ls in [(lim_sup, "--"), (lim_inf, "--")]:
    axes[0,1].axvline(v[0], color="gray", ls=ls, lw=0.8)
    axes[0,1].axhline(v[1], color="gray", ls=ls, lw=0.8)
axes[0,1].set_xlabel("temp_zona1"); axes[0,1].set_ylabel("temp_zona2")
axes[0,1].legend(fontsize=8)
axes[0,1].set_title("Região retangular (cartas individuais)\nvs elipse real de controlo")
axes[1,0].bar(range(1, p+1), var_exp, color="#00688f")
axes[1,0].plot(range(1, p+1), np.cumsum(var_exp), "ro-")
axes[1,0].axhline(0.9, color="gray", ls=":"); axes[1,0].set_xlabel("componente")
axes[1,0].set_title("Variância explicada por componente")
axes[1,1].scatter(t2_pca, spe, s=14, alpha=0.6)
axes[1,1].scatter(t2_pca[-3:], spe[-3:], color="red", s=90, marker="X")
axes[1,1].axvline(t2_pca_lim, color="r", ls="--"); axes[1,1].axhline(spe_lim, color="r", ls="--")
axes[1,1].set_xlabel("T² (PCA)"); axes[1,1].set_ylabel("SPE / Q")
axes[1,1].set_title("T² × SPE — as duas estatísticas em conjunto")
plt.tight_layout(); plt.show()
```

**Engineering reading.** Anomaly (a)'s result is this chapter's decisive argument: **no individual chart signals anything** — both temperatures are within the 3σ limits — but the combination is strongly anomalous, because the two zones normally move together (correlation of 0.88) and here they diverged.

Physically, this is exactly what you'd see with a broken zone heater or a shifted thermocouple. It's a real, common failure mode, and it's **invisible** to univariate SPC.

The contribution decomposition completes the tool: it identifies the two temperatures as responsible, pointing the investigation directly at the heating system.

**On PCA and SPE.** Notice that anomaly (c) — one variable way out — shows up strongly in the SPE, because it breaks the correlation structure the model learned. Anomaly (b), a joint shift in the direction of normal variation, shows up in the T² but barely affects the SPE. **The two statistics detect different things**, which is why both get monitored.

### Excel and Power BI (DAX)

PCA and Hotelling's $T^2$ statistic require eigenvalue/eigenvector decomposition of a covariance matrix — Excel has no native function for that (`MDETERM`/`MINVERSE` handle the matrix inversion used in $T^2$ for a few variables, but not the spectral decomposition PCA needs). This is one of the few areas in this manual where the honest answer is: **don't force it into Excel here**.

```py-r
--- excel
' T2 de Hotelling para p<=3 variaveis e viavel calculando manualmente com MINVERSE/MMULT
' (distancia de Mahalanobis), mas torna-se impraticavel e propenso a erro acima disso.
' Nao existe equivalente pratico de PCA nativo em Excel sem suplementos (ex.: XLSTAT).
```

**Power BI's proper role here isn't to calculate, it's to watch.** After the PCA and the $T^2$ control limit are calculated in Python/R (as in the example above), publish the $T^2$ series by lot/time as a simple measure — a red/green card comparing the value against the control limit — but the calculation of $T^2$ itself, of the principal components, and of the SPE/DModX decomposition stays in Python/R. Trying to reproduce PCA in DAX would be fragilely reinventing what statistical libraries already do in a proven way.

### Common mistakes

1. **Keeping 20 univariate charts and ignoring correlation.** Inflates false alarms and misses correlation failure modes.
2. **Using T² without a decomposition tool.** A signal with no diagnosis isn't actionable, and the team ends up ignoring the chart.
3. **Estimating $\mathbf{S}$ with too few observations.** Rule of thumb: at least $10p$ observations in Phase I, and more if the correlations are strong.
4. **PCA without standardizing.** If the variables have different scales (rpm in the thousands, pressure in units), the principal component will be dominated by the largest-scale variable. Always standardize.
5. **Monitoring only T² and forgetting SPE.** You lose exactly the most informative class of anomalies: the ones the model has never seen.
6. **Retaining components by a fixed rule with no look at interpretation.** A component that doesn't correspond to anything physically recognizable is a sign the model is fitting noise.
