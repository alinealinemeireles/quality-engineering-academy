## Chapter 53: Count Data: Poisson, Negative Binomial, and the Generalized Linear Model
### The engineering question

*I'm counting defects — but is the variation I observe the variation the model predicts?*

Counts of defects per unit, per meter, per panel, or per hour are everywhere in quality. The natural model is Poisson, with a very restrictive property:

$$X \sim \text{Poisson}(\lambda) \;\Longrightarrow\; E[X] = \text{Var}[X] = \lambda$$

**Variance isn't a free parameter.** It's determined by the mean. When the real variation exceeds what's predicted — a situation called **overdispersion** — every confidence interval and p-value becomes too narrow, and the analyst concludes there are significant effects where there aren't.

Overdispersion is the rule, not the exception, in industrial data: different raw-material lots, different machines, different shifts all introduce heterogeneity that Poisson doesn't account for.

### The generalized linear model (GLM) framework

A GLM has three components: a **distribution**, a **link function**, and a **linear predictor**.

$$g(E[Y]) = \beta_0 + \beta_1 X_1 + \dots + \beta_p X_p$$

| Response type | Distribution | Link | Use in quality |
|---|---|---|---|
| Continuous, symmetric | Normal | identity | Classic regression |
| Binary | Binomial | logit | Conforming/nonconforming |
| Proportion of $n$ | Binomial | logit | Defective fraction per lot |
| Count | Poisson | log | Defects per unit |
| Overdispersed count | **Negative Binomial** | log | Defects with heterogeneity |
| Skewed positive continuous | Gamma | log or inverse | Repair time, cost |
| Zero-inflated count | ZIP / ZINB | log + logit | Rare defects with many zeros |

**Linear regression is a special case of the GLM.** Seeing it this way unifies the material: instead of memorizing "which test to use," you choose the distribution that describes the response and the link that makes the effect additive.

**The exposure quantity (*offset*).** If the observed units have different sizes (panels of different area, shifts of different duration), you don't model the raw count — you model the **rate**:

$$\ln(E[Y]) = \ln(\text{exposure}) + \beta_0 + \sum \beta_j X_j$$

The $\ln(\text{exposure})$ term enters with its coefficient fixed at 1 — that's the *offset*. Forgetting it is a serious and common mistake: it turns size differences into spurious effects.

### Worked example: defects per panel

```py-r
--- python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(88)
n = 400

area = rng.uniform(0.8, 2.4, n)                 # m² por painel (exposição)
velocidade = rng.uniform(8, 20, n)              # m/min
turno = rng.choice(["M", "T", "N"], n)
lote = rng.integers(0, 25, n)                   # 25 lotes de matéria-prima

# Verdade: taxa cresce com a velocidade; turno N pior; heterogeneidade entre lotes
efeito_lote = rng.normal(0, 0.45, 25)           # <- gera SOBREDISPERSÃO
log_taxa = -2.4 + 0.11*velocidade + 0.35*(turno == "N") + efeito_lote[lote]
defeitos = rng.poisson(np.exp(log_taxa) * area)

d = pd.DataFrame({"defeitos": defeitos, "area": area, "velocidade": velocidade,
                  "turno": turno, "lote": lote})
d["log_area"] = np.log(d["area"])

print(f"n = {n} painéis | total de defeitos = {d['defeitos'].sum()}")
print(f"Média = {d['defeitos'].mean():.3f} | Variância = {d['defeitos'].var(ddof=1):.3f}"
      f"  ->  rácio V/M = {d['defeitos'].var(ddof=1)/d['defeitos'].mean():.2f}")
print("(Poisson exige V/M ≈ 1; valores muito acima indicam sobredispersão)\n")

# ---------- Modelo 1: Poisson COM offset ----------
p1 = smf.glm("defeitos ~ velocidade + C(turno)", data=d,
             family=sm.families.Poisson(), offset=d["log_area"]).fit()
disp = p1.pearson_chi2 / p1.df_resid
print("MODELO 1 — Poisson com offset log(área)")
print(p1.summary2().tables[1].round(4).to_string())
print(f"\n  Estatística de dispersão (Pearson chi2 / gl) = {disp:.3f}")
print(f"  => {'SOBREDISPERSÃO CONFIRMADA' if disp > 1.5 else 'dispersão aceitável'}"
      f" — os erros-padrão acima estão subestimados por um fator ≈ {np.sqrt(disp):.2f}\n")

# ---------- Modelo 2: Binomial Negativa ----------
nb = smf.glm("defeitos ~ velocidade + C(turno)", data=d,
             family=sm.families.NegativeBinomial(alpha=1.0),
             offset=d["log_area"]).fit()
# estimar alpha por perfil de verosimilhança
alphas = np.linspace(0.05, 1.5, 60)
llf = [smf.glm("defeitos ~ velocidade + C(turno)", data=d,
               family=sm.families.NegativeBinomial(alpha=a),
               offset=d["log_area"]).fit().llf for a in alphas]
alpha_hat = alphas[int(np.argmax(llf))]
nb = smf.glm("defeitos ~ velocidade + C(turno)", data=d,
             family=sm.families.NegativeBinomial(alpha=alpha_hat),
             offset=d["log_area"]).fit()
print(f"MODELO 2 — Binomial Negativa (alpha estimado = {alpha_hat:.3f})")
print(nb.summary2().tables[1].round(4).to_string())

# ---------- Comparação dos erros-padrão ----------
cmp = pd.DataFrame({
    "Coef (Poisson)": p1.params.round(4),
    "EP (Poisson)": p1.bse.round(4),
    "p (Poisson)": p1.pvalues.round(4),
    "Coef (Bin.Neg)": nb.params.round(4),
    "EP (Bin.Neg)": nb.bse.round(4),
    "p (Bin.Neg)": nb.pvalues.round(4),
})
cmp["EP inflacionado"] = (nb.bse/p1.bse).round(2)
print("\nCOMPARAÇÃO — o efeito de ignorar a sobredispersão")
print(cmp.to_string())
print(f"\nAIC: Poisson = {p1.aic:.1f} | Binomial Negativa = {nb.aic:.1f}"
      f"  -> {'Bin.Neg. muito melhor' if nb.aic < p1.aic - 10 else 'semelhantes'}")

# ---------- Interpretação ----------
print("\nINTERPRETAÇÃO (modelo Binomial Negativa):")
print(f"  • Cada +1 m/min multiplica a taxa de defeitos por "
      f"{np.exp(nb.params['velocidade']):.4f}")
print(f"    -> passar de 10 para 16 m/min: fator "
      f"{np.exp(6*nb.params['velocidade']):.2f}x mais defeitos por m²")
if "C(turno)[T.N]" in nb.params:
    print(f"  • Turno N vs manhã: taxa {np.exp(nb.params['C(turno)[T.N]']):.2f}x")

# ---------- Consequência de esquecer o offset ----------
sem_offset = smf.glm("defeitos ~ velocidade + C(turno)", data=d,
                     family=sm.families.NegativeBinomial(alpha=alpha_hat)).fit()
print(f"\nE se esquecêssemos o offset?")
print(f"  Coef. velocidade COM offset  = {nb.params['velocidade']:.4f}")
print(f"  Coef. velocidade SEM offset  = {sem_offset.params['velocidade']:.4f}")
print(f"  => o efeito da área contamina os restantes coeficientes.")

fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].hist(d["defeitos"], bins=range(0, d["defeitos"].max()+2),
             density=True, alpha=0.65, color="#6fa8be", edgecolor="white", label="observado")
lam = d["defeitos"].mean()
ks = np.arange(0, d["defeitos"].max()+1)
axes[0].plot(ks, stats.poisson.pmf(ks, lam), "o-", color="crimson",
             label=f"Poisson(λ={lam:.2f})")
axes[0].legend(fontsize=8); axes[0].set_title("Distribuição das contagens")
axes[1].scatter(p1.fittedvalues, p1.resid_pearson, s=12, alpha=0.6)
axes[1].axhline(0, color="r", ls="--"); axes[1].axhline(2, color="gray", ls=":")
axes[1].axhline(-2, color="gray", ls=":")
axes[1].set_title(f"Poisson: resíduos de Pearson\n(dispersão = {disp:.2f})")
axes[2].scatter(nb.fittedvalues, nb.resid_pearson, s=12, alpha=0.6, color="green")
axes[2].axhline(0, color="r", ls="--"); axes[2].axhline(2, color="gray", ls=":")
axes[2].axhline(-2, color="gray", ls=":")
axes[2].set_title(f"Binomial Negativa: resíduos\n(dispersão = "
                  f"{nb.pearson_chi2/nb.df_resid:.2f})")
plt.tight_layout(); plt.show()
```

```py-r
--- r
set.seed(88)
n <- 400
area <- runif(n, 0.8, 2.4); velocidade <- runif(n, 8, 20)
turno <- sample(c("M","T","N"), n, TRUE); lote <- sample(0:24, n, TRUE)
ef_lote <- rnorm(25, 0, 0.45)
log_taxa <- -2.4 + 0.11*velocidade + 0.35*(turno == "N") + ef_lote[lote+1]
defeitos <- rpois(n, exp(log_taxa)*area)
d <- data.frame(defeitos, area, velocidade, turno = factor(turno))

cat(sprintf("Media = %.3f | Variancia = %.3f | V/M = %.2f\n\n",
            mean(defeitos), var(defeitos), var(defeitos)/mean(defeitos)))

p1 <- glm(defeitos ~ velocidade + turno + offset(log(area)),
          data = d, family = poisson)
cat("POISSON com offset:\n"); print(summary(p1)$coefficients)
disp <- sum(residuals(p1, type = "pearson")^2) / p1$df.residual
cat(sprintf("Dispersao = %.3f -> %s\n\n", disp,
            ifelse(disp > 1.5, "SOBREDISPERSAO", "ok")))

# Quasi-Poisson: corrige os erros-padrao sem mudar os coeficientes
q1 <- glm(defeitos ~ velocidade + turno + offset(log(area)),
          data = d, family = quasipoisson)
cat("QUASI-POISSON (erros-padrao corrigidos):\n")
print(summary(q1)$coefficients)
cat(sprintf("\nTaxa multiplica por %.4f a cada +1 m/min\n",
            exp(coef(q1)["velocidade"])))
```

**Engineering reading.** The standard-error comparison is the central result. Ignoring overdispersion doesn't change the coefficient estimates — it changes the **confidence** placed in them. Underestimated standard errors produce confidence intervals that are too narrow and p-values that are too small, and that's how you "discover" effects that don't exist.

**On the source of overdispersion in this example:** it comes from heterogeneity between raw-material lots. There are two legitimate ways to handle it:

1. **Negative Binomial** (or quasi-Poisson) — treats the heterogeneity as extra noise to absorb. Correct when the lots themselves aren't of interest.
2. **Mixed model with a random lot effect** — treats the lot as an identified source of variation and **quantifies it**. Correct when we want to know how much of the total variation comes from the supplier. That's the next chapter's topic.

The choice between the two isn't statistical, it's an engineering choice: it depends on whether the between-lot variation is noise to accommodate or a problem to attack.

### Excel and Power BI (DAX)

Excel also doesn't fit Poisson/negative-binomial GLMs natively, but it has a genuinely useful function here: `POISSON.DIST`, which at least lets you **validate** the equidispersion assumption on a sample, without needing statistical software.

```py-r
--- excel
' Indice de dispersao (deveria ser ~1 sob Poisson; >1.5 indica sobredispersao):
=VAR.P(Defeitos_range)/MEDIA(Defeitos_range)
' Probabilidade de um valor observado sob Poisson com a taxa media estimada:
=POISSON.DIST(k; MEDIA(Defeitos_range); FALSO)
--- dax
Indice de Dispersao :=
DIVIDE ( VAR.P ( Inspecoes[Defeitos] ), AVERAGE ( Inspecoes[Defeitos] ) )

Sinaliza Sobredispersao :=
IF ( [Indice de Dispersao] > 1.5, "Poisson não serve — usar binomial negativa", "Poisson adequada" )
```

The `Indice de Dispersao` measure is exactly the informal test described under "Common mistakes" below (Pearson χ²/df), made visible on a dashboard card — a cheap early-warning signal for deciding, before any Python/R modeling, whether it's worth jumping straight to negative binomial.

### Common mistakes

1. **Forgetting the offset.** Modeling counts without correcting for exposure turns size differences into spurious effects.
2. **Not checking dispersion.** Always compute Pearson χ²/df. Above 1.5, Poisson doesn't fit.
3. **Using ANOVA on counts.** Small counts violate normality and homoscedasticity. The $\sqrt{x}$ transform is an old patch; the GLM is the modern solution.
4. **Confusing overdispersion with excess zeros.** If there are more zeros than any count predicts (for example, because some panels never even got processed), the model is ZIP or a *hurdle* model, not negative binomial.
5. **Interpreting log-link coefficients as additive.** They're multiplicative: $e^{\beta}$.
