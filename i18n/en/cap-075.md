## Chapter 75: Fractional Factorials: Resolution, Generators, and Alias Structure ✦

### The engineering question

*I have 7 factors and budget for 16 runs. What will I lose the ability to tell apart?*

A full factorial with 7 factors at 2 levels requires 128 runs. A $2^{7-3}$ fractional factorial requires 16. The savings aren't free: you pay for them in **confounding**, and the engineering work is choosing **which** confounding to accept.

This is the difference between using a DOE and designing a DOE.

### Generators, the defining relation, and aliases

In a $2^{k-p}$, you choose $p$ **generators** that define the extra factors' columns from the interactions of the $k-p$ base factors.

Example with $2^{7-3}$ (7 factors in 16 runs): base factors A, B, C, D; generators

$$E = ABC, \qquad F = BCD, \qquad G = ACD$$

The **defining relation** is the product of all the generating words and their combinations:

$$I = ABCE = BCDF = ACDG = ADEF = BDEG = ABFG = CEFG$$

The **resolution** is the length of the shortest word in the defining relation. Here, 4 → **Resolution IV**.

| Resolution | Shortest word | Main effects confounded with | When to use |
|---|---|---|---|
| **III** | 3 letters | 2-factor interactions | Screening many factors; assumes interactions are negligible |
| **IV** | 4 letters | 3-factor interactions (clean) — but **2-factor interactions are confounded with each other** | Robust screening. The most common compromise |
| **V** | 5 letters | 4-factor interactions; **2-factor interactions clean** | Characterization and optimization |

> **The rule of thumb:** resolution III for "which of the 11 factors matter?", resolution IV for "which matter, and are there interactions to explore afterward?", resolution V for "I want the model."

**The projection property** is what makes fractionals powerful and is often forgotten: a resolution-R design projects onto a **full factorial in any $R-1$ factors**. A $2^{7-3}_{IV}$ contains a replicated full factorial in any 3 factors. If screening identifies 3 active factors, you already have the full factorial — without running anything else.

### Worked example: building the design and reading the aliases

```py-r
--- python
import numpy as np
import pandas as pd
from itertools import product, combinations

def fatorial_fracionado(k_base, geradores):
    """Constrói um 2^(k-p). geradores: dict {'E': 'ABC', ...}"""
    base = [chr(65+i) for i in range(k_base)]
    linhas = list(product([-1, 1], repeat=k_base))
    d = pd.DataFrame(linhas, columns=base)
    for novo, palavra in geradores.items():
        col = np.ones(len(d), dtype=int)
        for letra in palavra:
            col = col * d[letra].values
        d[novo] = col
    return d

def relacao_definidora(geradores):
    """Palavras da relação definidora (I = ...) a partir dos geradores."""
    palavras_base = [set(p) | {novo} for novo, p in geradores.items()]
    todas = set()
    for r in range(1, len(palavras_base)+1):
        for combo in combinations(palavras_base, r):
            palavra = set()
            for s in combo:
                palavra ^= s              # diferença simétrica: X*X = I
            if palavra:
                todas.add("".join(sorted(palavra)))
    return sorted(todas, key=lambda w: (len(w), w))

def aliases_de(efeito, palavras):
    out = set()
    for w in palavras:
        a = set(efeito) ^ set(w)
        if a:
            out.add("".join(sorted(a)))
    return sorted(out, key=lambda x: (len(x), x))

geradores = {"E": "ABC", "F": "BCD", "G": "ACD"}
d = fatorial_fracionado(4, geradores)
palavras = relacao_definidora(geradores)
resolucao = min(len(w) for w in palavras)

print(f"Desenho 2^(7-3): {len(d)} corridas para 7 fatores "
      f"(fatorial completo exigiria {2**7})")
print(f"Fração = 1/{2**3} do completo\n")
print("RELAÇÃO DEFINIDORA")
print("   I = " + " = ".join(palavras))
print(f"\nRESOLUÇÃO = {resolucao} ({'III' if resolucao==3 else 'IV' if resolucao==4 else 'V+'})")

print("\nESTRUTURA DE ALIASES (até interações de 2 fatores)")
fatores = list(d.columns)
for f in fatores:
    al = [a for a in aliases_de(f, palavras) if len(a) <= 3]
    print(f"   {f:<4} = " + " = ".join(al))
print()
pares = ["".join(sorted(c)) for c in combinations(fatores, 2)]
vistos = set(); grupos = []
for p in pares:
    if p in vistos: continue
    grupo = [p] + [a for a in aliases_de(p, palavras) if len(a) == 2]
    for g in grupo: vistos.add(g)
    grupos.append(sorted(set(grupo)))
print("   Interações de 2 fatores confundidas entre si:")
for g in grupos:
    if len(g) > 1:
        print(f"      {' = '.join(g)}")

print("\nMATRIZ DO DESENHO (primeiras 8 corridas de 16)")
print(d.head(8).to_string(index=False))

# --- Propriedade de projeção ---
print("\nPROPRIEDADE DE PROJEÇÃO")
for trio in [("A","B","C"), ("A","D","F"), ("B","E","G")]:
    sub = d[list(trio)].drop_duplicates()
    reps = len(d)//len(sub)
    print(f"   Projetando em {trio}: {len(sub)} combinações distintas "
          f"({'fatorial COMPLETO' if len(sub)==8 else 'incompleto'}), "
          f"{reps} réplicas cada")
```

### Worked example: screening 7 factors and the next step

```py-r
--- python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats

rng = np.random.default_rng(707)

# --- Verdade desconhecida: só B, D e a interação BD são ativos ---
def resposta(df, ruido=1.2, seed=707):
    r = np.random.default_rng(seed)
    return (52.0 + 4.5*df["B"] + 3.1*df["D"] + 2.4*df["B"]*df["D"]
            + 0.6*df["A"] + r.normal(0, ruido, len(df)))

d["Y"] = resposta(d)

# --- Estimar efeitos (metade da diferença entre médias, como é convenção em DOE) ---
efeitos = {}
for f in fatores:
    efeitos[f] = d.loc[d[f]==1, "Y"].mean() - d.loc[d[f]==-1, "Y"].mean()
for c in combinations(fatores, 2):
    col = d[c[0]]*d[c[1]]
    nome = "".join(sorted(c))
    efeitos[nome] = d.loc[col==1, "Y"].mean() - d.loc[col==-1, "Y"].mean()

ef = pd.Series(efeitos).sort_values(key=np.abs, ascending=False)

# --- Pseudo-erro-padrão de Lenth: identifica efeitos ativos SEM réplicas ---
def lenth(efs):
    e = np.abs(np.asarray(efs))
    s0 = 1.5*np.median(e)
    pse = 1.5*np.median(e[e < 2.5*s0])
    return pse

todos_ef = ef.values
pse = lenth(todos_ef)
m = len(todos_ef)
t_crit = stats.t.ppf(1 - 0.05/2, max(m//3, 1))
ME = t_crit * pse                                  # margem de erro
SME = stats.t.ppf((1 + 0.95**(1/m))/2, max(m//3,1)) * pse   # margem simultânea

print(f"Pseudo-erro-padrão de Lenth (PSE) = {pse:.3f}")
print(f"Margem de erro (ME)            = {ME:.3f}")
print(f"Margem simultânea (SME)        = {SME:.3f}\n")

tab = pd.DataFrame({"Efeito": ef.index, "Estimativa": ef.values.round(3)})
tab["Ativo (ME)"] = np.where(np.abs(ef.values) > ME, "SIM", "")
tab["Ativo (SME)"] = np.where(np.abs(ef.values) > SME, "SIM", "")
tab["Aliases"] = [" = ".join([a for a in aliases_de(e, palavras) if len(a) <= 3][:3])
                  for e in ef.index]
print(tab.head(12).to_string(index=False))

ativos = [e for e in ef.index if abs(ef[e]) > ME]
print(f"\nEfeitos ativos: {ativos}")
print("\nA AMBIGUIDADE — e é aqui que o desenho de resolução IV cobra o preço:")
for a in ativos:
    if len(a) == 2:
        conf = [x for x in aliases_de(a, palavras) if len(x) == 2]
        print(f"   O efeito '{a}' está confundido com {conf}.")
        print(f"   Os dados NÃO conseguem dizer qual destas interações é a real.")

print("\nCOMO RESOLVER — corrida de desconfundimento (fold-over):")
print("   Acrescentar 16 corridas com os sinais de um fator invertidos separa")
print("   as interações confundidas. Custa metade do que custaria repetir tudo.")
print("   Alternativa mais barata: se a engenharia souber que, por exemplo, A e G")
print("   não interagem fisicamente, a ambiguidade resolve-se por conhecimento")
print("   do processo — que é sempre a opção mais económica.")

fig, axes = plt.subplots(1, 2, figsize=(13, 4.5))
cores = ["#a5203a" if abs(v) > ME else "#93a7ae" for v in ef.values[:15]]
axes[0].barh(range(15), ef.values[:15][::-1], color=cores[::-1])
axes[0].set_yticks(range(15)); axes[0].set_yticklabels(ef.index[:15][::-1], fontsize=8)
axes[0].axvline(ME, color="r", ls="--"); axes[0].axvline(-ME, color="r", ls="--")
axes[0].set_title("Gráfico de Pareto dos efeitos (linhas = margem de Lenth)")

# Gráfico de probabilidade normal dos efeitos
ordenados = np.sort(todos_ef)
pp = (np.arange(1, len(ordenados)+1) - 0.5)/len(ordenados)
z = stats.norm.ppf(pp)
axes[1].scatter(ordenados, z, s=25)
for i, v in enumerate(ordenados):
    if abs(v) > ME:
        nome = ef.index[list(ef.values).index(v)]
        axes[1].annotate(nome, (v, z[i]), fontsize=8, xytext=(4,0),
                         textcoords="offset points")
axes[1].axvline(0, color="gray", lw=0.8)
axes[1].set_xlabel("efeito estimado"); axes[1].set_ylabel("quantil normal")
axes[1].set_title("Gráfico normal dos efeitos\n(pontos fora da reta = efeitos reais)")
plt.tight_layout(); plt.show()
```

```py-r
--- python
%%R
# Construcao de um 2^(7-3) com geradores E=ABC, F=BCD, G=ACD
base <- expand.grid(A=c(-1,1), B=c(-1,1), C=c(-1,1), D=c(-1,1))
base$E <- base$A*base$B*base$C
base$F <- base$B*base$C*base$D
base$G <- base$A*base$C*base$D

set.seed(707)
base$Y <- 52 + 4.5*base$B + 3.1*base$D + 2.4*base$B*base$D +
          0.6*base$A + rnorm(nrow(base), 0, 1.2)

cat(sprintf("Desenho: %d corridas, 7 fatores\n\n", nrow(base)))

fatores <- c("A","B","C","D","E","F","G")
ef <- sapply(fatores, function(f)
  mean(base$Y[base[[f]] == 1]) - mean(base$Y[base[[f]] == -1]))
pares <- combn(fatores, 2, simplify = FALSE)
ef2 <- sapply(pares, function(p) {
  col <- base[[p[1]]] * base[[p[2]]]
  mean(base$Y[col == 1]) - mean(base$Y[col == -1])
})
names(ef2) <- sapply(pares, paste, collapse = "")
todos <- c(ef, ef2)

# Metodo de Lenth
lenth <- function(e) { s0 <- 1.5*median(abs(e)); 1.5*median(abs(e)[abs(e) < 2.5*s0]) }
pse <- lenth(todos)
ME <- qt(0.975, max(length(todos) %/% 3, 1)) * pse
cat(sprintf("PSE de Lenth = %.3f | Margem de erro = %.3f\n\n", pse, ME))
print(round(sort(todos[abs(todos) > ME], decreasing = TRUE), 3))
```

**Engineering reading.** The example shows the full cycle of a screening study: 16 runs identify 2 main factors and 1 interaction out of 7 candidates — and they also identify **what remains unknown**.

Lenth's method deserves a highlight: it lets you decide which effects are real **with no replicates at all**, using the median of the small effects as a noise estimate. That's what makes an unreplicated design viable, and it's why industrial screening doesn't need to double the number of runs.

**The simultaneous margin (SME) versus the individual margin (ME).** With 28 effects evaluated, using only ME produces false positives from multiple comparisons. Effects between ME and SME are "candidates"; above SME they're convincing. Reporting both is correct practice.

### Excel and Power BI

Estimating an individual effect in a fractional factorial is, just as in the previous chapter, a sum of products over the effect's coded column:

```py-r
--- excel
' Estimativa de um efeito (incluindo efeitos "gerados", como E, F, G) a partir
' da coluna codificada correspondente (+1/-1), ja construida segundo os
' geradores do desenho:
=SOMARPRODUTO(ColunaEfeito;ColunaY)/(CONTAGEM(ColunaY)/2)
```

**What Excel doesn't do on its own:** deriving the **defining relation** and the **alias structure** from the generators is an exercise in mod-2 algebra (multiplying coded columns and reducing $A^2=1$) — it can be done manually, cell by cell, for small designs, but it's the kind of task where a typo is easy and expensive, because it leads to interpreting a confounded effect as if it were clean. For resolution IV or V designs with many factors, generate the alias structure in Python/R (as in the worked example) and use Excel only for the final step of estimating the effects already identified as interesting.

### Common mistakes

1. **Choosing the fraction by the number of runs instead of by resolution.** "I can fit 16 runs" isn't a design criterion. The question is which alias structure is acceptable.
2. **Not writing out the alias structure before running the trial.** This is the moment you discover the effect you care about most is confounded with another, equally plausible one — and there's still time to change the design.
3. **Interpreting a 2-factor effect in a resolution-IV design as if it were unique.**
4. **Randomizing "whenever convenient."** Randomization protects against uncontrolled factors (ambient temperature, tool wear, operator learning). Without it, the estimated effect can be a pure time artifact.
5. **Not including center points.** With 2 levels, a curved effect is invisible. See the next chapter.
6. **Wasting the projection property.** After identifying 3 active factors, many people run a new full factorial — which is already contained in the existing data.
