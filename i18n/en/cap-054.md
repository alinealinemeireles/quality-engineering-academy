## Chapter 54: Mixed Models: How Much Variation Comes from Where
### The engineering question

*Of the total variation I observe, how much comes from the supplier, how much from the machine, how much from the operator, and how much from the part?*

This is one of the most useful questions in quality engineering, and classic regression doesn't answer it. Regression estimates **effects of specific levels**; mixed models estimate **variance components** — how much each source contributes to total variability.

If this reasoning sounds familiar, it's because you've already used it: **Gage R&R is a variance-components model.** Repeatability and reproducibility are exactly that.

### Fixed effects and random effects

The distinction isn't about the math, it's about the **question**:

| | **Fixed** effect | **Random** effect |
|---|---|---|
| Question | "What's the difference between **these** levels?" | "How much variation exists **between** levels of this population?" |
| The levels are | All the ones that matter | A sample from a larger population |
| Example | Supplier A vs. B (the only two) | 25 lots from a population of lots |
| Example | Old method vs. new | 12 operators from a team of 200 |
| Result | Coefficients | Variance components |

**A mixed model has both:**

$$Y_{ij} = \underbrace{\beta_0 + \beta_1 X_{ij}}_{\text{fixed}} + \underbrace{u_i}_{\text{random}} + \varepsilon_{ij}, \qquad u_i \sim N(0, \sigma_u^2), \;\; \varepsilon_{ij} \sim N(0, \sigma^2)$$

**Intraclass correlation coefficient (ICC):**

$$ICC = \frac{\sigma_u^2}{\sigma_u^2 + \sigma^2}$$

It's the fraction of total variance attributable to the grouping. An ICC of 0.40 means 40% of the variation is **between** lots and only 60% within them.

> **Why this is critical:** grouped data isn't independent. If you ignore the grouping and fit a simple regression, the standard errors are underestimated and the effective number of observations is much lower than it appears. With 400 parts from 25 lots and an ICC of 0.4, the **effective sample size** is around 55 independent observations, not 400.

### Worked example: decomposing the variation of a multi-source process

```py-r
--- python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt

rng = np.random.default_rng(404)

n_lotes, n_maquinas, n_por_celula = 20, 4, 6

# Componentes de variância verdadeiros
sd_lote, sd_maquina, sd_residuo = 0.28, 0.16, 0.20
ef_lote = rng.normal(0, sd_lote, n_lotes)
ef_maq = rng.normal(0, sd_maquina, n_maquinas)

linhas = []
for l in range(n_lotes):
    for m in range(n_maquinas):
        for _ in range(n_por_celula):
            temp = rng.normal(180, 8)              # efeito fixo real: +0,012 por °C
            y = (25.0 + 0.012*(temp-180) + ef_lote[l] + ef_maq[m]
                 + rng.normal(0, sd_residuo))
            linhas.append({"y": y, "lote": f"L{l:02d}", "maquina": f"M{m}",
                           "temp": temp})
d = pd.DataFrame(linhas)
print(f"n = {len(d)} peças | {n_lotes} lotes × {n_maquinas} máquinas × {n_por_celula} peças\n")

# ---------- Abordagem INGÉNUA: regressão simples ----------
ols = smf.ols("y ~ temp", data=d).fit()
print("1) REGRESSÃO SIMPLES (ignora o agrupamento)")
print(f"   coef(temp) = {ols.params['temp']:.5f}  EP = {ols.bse['temp']:.5f}  "
      f"p = {ols.pvalues['temp']:.4g}")
print(f"   sigma residual = {np.sqrt(ols.mse_resid):.4f}")
print("   => trata as 480 peças como independentes. Não são.\n")

# ---------- Modelo misto: lote como efeito aleatório ----------
mm = smf.mixedlm("y ~ temp", data=d, groups=d["lote"]).fit(reml=True)
v_lote = float(mm.cov_re.iloc[0, 0]); v_res = float(mm.scale)
print("2) MODELO MISTO — lote como efeito aleatório")
print(f"   coef(temp) = {mm.params['temp']:.5f}  EP = {mm.bse['temp']:.5f}  "
      f"p = {mm.pvalues['temp']:.4g}")
print(f"   Var(lote) = {v_lote:.5f}  (sd = {np.sqrt(v_lote):.4f}, real {sd_lote})")
print(f"   Var(resíduo) = {v_res:.5f}  (sd = {np.sqrt(v_res):.4f})")
print(f"   ICC = {v_lote/(v_lote+v_res):.3f}")
n_eff = len(d) / (1 + (n_maquinas*n_por_celula - 1) * v_lote/(v_lote+v_res))
print(f"   Tamanho de amostra EFETIVO ≈ {n_eff:.0f} (em vez de {len(d)})\n")

# ---------- Modelo com dois efeitos aleatórios CRUZADOS ----------
# Efeitos cruzados (lote e máquina não estão aninhados um no outro) declaram-se
# com um grupo único artificial + componentes de variância.
d["todos"] = 1
mm2 = smf.mixedlm("y ~ temp", data=d, groups=d["todos"],
                  vc_formula={"lote": "0 + C(lote)",
                              "maquina": "0 + C(maquina)"}).fit(reml=True)
v_lote2, v_maq2 = float(mm2.vcomp[0]), float(mm2.vcomp[1])
v_res2 = float(mm2.scale)
total = v_lote2 + v_maq2 + v_res2
print("3) MODELO MISTO — lote E máquina como efeitos aleatórios cruzados")
comp = pd.DataFrame({
    "Fonte": ["Lote (matéria-prima)", "Máquina", "Resíduo (peça a peça)"],
    "Variância": [v_lote2, v_maq2, v_res2],
    "Desvio-padrão": [np.sqrt(v_lote2), np.sqrt(v_maq2), np.sqrt(v_res2)],
    "sd real": [sd_lote, sd_maquina, sd_residuo],
})
comp["% da variância total"] = (comp["Variância"]/total*100).round(1)
print(comp.round(5).to_string(index=False))
print(f"\n   Desvio-padrão TOTAL do processo = {np.sqrt(total):.4f}")

# ---------- A decisão de engenharia ----------
print("\nDECISÃO DE ENGENHARIA — se eliminássemos completamente cada fonte:")
LSL, USL = 24.0, 26.0
for fonte, v in [("Lote", v_lote2), ("Máquina", v_maq2), ("Resíduo", v_res2)]:
    novo_sd = np.sqrt(total - v)
    cp_antes = (USL-LSL)/(6*np.sqrt(total)); cp_dep = (USL-LSL)/(6*novo_sd)
    print(f"   Eliminar '{fonte:<8}': sd {np.sqrt(total):.4f} -> {novo_sd:.4f}"
          f"  |  Cp {cp_antes:.2f} -> {cp_dep:.2f}  (+{cp_dep-cp_antes:.2f})")
print("\n=> É esta tabela que diz onde investir. A maior componente é o alvo.")

fig, axes = plt.subplots(1, 2, figsize=(13, 4))
d.boxplot(column="y", by="lote", ax=axes[0], grid=False)
axes[0].set_title("Variação entre lotes"); axes[0].set_xlabel("")
plt.sca(axes[0]); plt.xticks(rotation=90, fontsize=6)
axes[1].pie(comp["Variância"], labels=comp["Fonte"], autopct="%1.1f%%",
            colors=["#a5203a", "#d17a00", "#00688f"])
axes[1].set_title("Decomposição da variância total")
plt.suptitle(""); plt.tight_layout(); plt.show()
```

```py-r
--- python
%%R
# nlme faz parte da distribuicao base do R (biblioteca recomendada)
if (requireNamespace("nlme", quietly = TRUE)) {
  library(nlme)
  set.seed(404)
  n_lotes <- 20; n_maq <- 4; n_cel <- 6
  ef_lote <- rnorm(n_lotes, 0, 0.28); ef_maq <- rnorm(n_maq, 0, 0.16)
  d <- do.call(rbind, lapply(1:n_lotes, function(l)
    do.call(rbind, lapply(1:n_maq, function(m) {
      temp <- rnorm(n_cel, 180, 8)
      data.frame(y = 25 + 0.012*(temp-180) + ef_lote[l] + ef_maq[m] + rnorm(n_cel, 0, 0.20),
                 lote = factor(sprintf("L%02d", l)), maquina = factor(paste0("M", m)),
                 temp = temp)
    }))))

  mm <- lme(y ~ temp, random = ~ 1 | lote, data = d, method = "REML")
  print(summary(mm)$tTable)
  vc <- VarCorr(mm)
  v_lote <- as.numeric(vc[1,1]); v_res <- as.numeric(vc[2,1])
  cat(sprintf("\nVar(lote) = %.5f | Var(residuo) = %.5f | ICC = %.3f\n",
              v_lote, v_res, v_lote/(v_lote+v_res)))

  # ANOVA de componentes de variancia (equivalente classico)
  cat("\nEquivalente classico — aov com Error():\n")
  print(summary(aov(y ~ temp + Error(lote/maquina), data = d)))
} else {
  cat("Pacote nlme nao disponivel neste ambiente.\n")
}
```

**Engineering reading.** The final table is this chapter's product, and it's the kind of output that turns statistics into an investment decision.

It answers the question management always asks: *"where should we spend the money?"* If 60% of the variance comes from the raw-material lots, no machine-improvement project will fix the capability problem — the right project is **supplier quality** (PART XII).

And notice the effect on effective sample size. With a substantial ICC, having 480 parts is statistically equivalent to having a few dozen independent observations. A hypothesis test that ignores this declares differences significant that aren't.

**The link to Gage R&R.** The crossed Gage R&R model is literally:

$$Y_{ijk} = \mu + P_i + O_j + (PO)_{ij} + \varepsilon_{ijk}$$

with part and operator as random effects. `Repeatability` = $\sigma^2_\varepsilon$; `Reproducibility` = $\sigma^2_O + \sigma^2_{PO}$. Whoever masters mixed models masters MSA — and can analyze cases standard Gage R&R software doesn't cover: **unbalanced, nested (destructive testing) studies, with more than two factors, or with covariates.**

### Excel and Power BI (DAX)

Unlike the previous chapters, this one has a genuinely industry-established Excel equivalent: the **ANOVA variance-components method**, used for decades in Gage R&R studies (see the MSA unit later on). The Data Analysis ToolPak's "Anova: Two-Factor" tool returns the Mean Squares; the variance components are then obtained by equating them to the expected mean squares (the classic method of moments, EMS):

```py-r
--- excel
' Apos rodar Dados > Analise de Dados > Anova: Fator Duplo com Repeticao,
' os quadrados medios (QM) de cada fonte permitem estimar os componentes de
' variancia pelas formulas classicas de EMS (Expected Mean Squares):
' sigma2_operador = (QM_Operador - QM_Interacao) / (n_pecas * n_repeticoes)
' sigma2_peca     = (QM_Peca - QM_Interacao) / (n_operadores * n_repeticoes)
' sigma2_interacao= (QM_Interacao - QM_Erro) / n_repeticoes
' sigma2_erro     = QM_Erro
```

**A limitation to state clearly:** this method (ANOVA + manual EMS) is exactly what Excel Gage R&R templates already do, and it works well for balanced, simple designs (2-3 crossed random factors). For unbalanced, nested designs, or with more sources of variation — like this chapter's example, with lot and machine — the manual method gets fragile, and `nlme`/`lme4` in R (already demonstrated above) or `statsmodels`/`pymer4` in Python remain the correct path. Power BI/DAX has no fitting role here — only displaying the already-computed variance-components table, as a stacked bar chart showing "where the variation comes from."

### Common mistakes

1. **Treating as fixed what's actually random.** If the 25 lots are a sample and the conclusion should generalize to future lots, they're random.
2. **Ignoring the grouping.** Produces underestimated standard errors and false positives. It's the most frequent mistake in industrial data analysis.
3. **Too few levels in the random effect.** With fewer than ~5 levels, between-group variance is poorly estimated. With 3 suppliers, treat them as fixed.
4. **Confusing nested with crossed.** Operators measuring *the same* parts: crossed. Different parts per operator (destructive testing): nested. The wrong structure attributes variation to the wrong source.
5. **Comparing models with different fixed effects using REML.** To compare fixed-effect structures, use maximum likelihood (ML); REML is for estimating variance components.
