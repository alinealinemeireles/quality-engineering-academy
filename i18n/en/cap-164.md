## Chapter 164: Multivariate Analysis II — Factor Analysis, Discriminant Analysis, and MANOVA


### The engineering question

*You have twenty process variables correlated with each other. You want to know which of them actually form groups with physical meaning — not just numbers that move together by statistical coincidence — and, once the groups are identified, you want to use that structure to classify new parts, or to compare a treatment's effect on several quality characteristics at once.*

Three different questions, three different tools. Factor analysis reduces many correlated variables to a small number of latent factors. Discriminant analysis uses many input variables to predict a single categorical output. MANOVA extends ANOVA to assess a factor's effect on several output variables simultaneously, instead of one at a time.

### Factor analysis: common variance, not total variance

Chapter 56 already covered PCA (principal component analysis), which decomposes the **total variance** of the data into orthogonal components, without distinguishing "meaningful" variance from measurement noise. Factor analysis starts from a different assumption: each observed variable is explained by a small number of unobserved **latent factors**, plus an error term specific to that variable:

$$x_i = \lambda_{i1} F_1 + \lambda_{i2} F_2 + \cdots + \lambda_{ik} F_k + \varepsilon_i$$

where $F_1, \ldots, F_k$ are the common factors, $\lambda_{ij}$ are the **factor loadings** (the strength of the relationship between variable $i$ and factor $j$), and $\varepsilon_i$ is that variable's specific variance — including measurement error. It's this separation between common variance (explained by the factors) and specific variance that distinguishes factor analysis from PCA: PCA uses all the variance; factor analysis uses only the part the variables share with each other. In industrial practice, this makes factor analysis better suited when the goal is identifying **latent causes** behind a set of correlated symptoms — for example, discovering that ten different surface-quality measurements are, in reality, manifestations of just two underlying physical factors (process temperature and tool wear).

### Discriminant analysis: many inputs, one categorical output

Linear discriminant analysis (LDA) answers a classification question: given a set of continuous input variables, which category (group, class, pass/fail lot) does a new observation most likely belong to? LDA builds linear combinations of the input variables that **maximize separation between groups** relative to the dispersion within each group — conceptually, the inverse of what ANOVA tests: instead of asking "do these groups have different means on one variable?", LDA asks "what combination of variables best separates these groups?" and then uses that combination to classify new cases. In quality engineering, a typical use is combining several process measurements (temperature, pressure, viscosity, cure time) into a single classification rule that predicts whether a lot will pass the final test — before the test is even run.

### MANOVA: one factor, several simultaneous outputs

Conventional ANOVA (Chapter 50) tests whether one or more factors affect **one** response variable. When the goal is assessing whether a factor affects **several** correlated responses at the same time — for example, whether a new raw-material supplier simultaneously affects hardness, roughness, and tensile strength of a part — running three separate ANOVAs inflates the type I error rate (Chapter 48) and ignores the correlation between the responses. MANOVA solves this by testing the factor's effect on the **vector** of responses all at once.

The most commonly reported test statistic is **Wilks' lambda** ($\Lambda$), which measures the proportion of total variance in the response variables **not** explained by the tested factor:

$$\Lambda = \frac{|\mathbf{E}|}{|\mathbf{E} + \mathbf{H}|}$$

where $\mathbf{E}$ is the residual (error) sum-of-squares-and-cross-products matrix, and $\mathbf{H}$ is the matrix corresponding to the factor's effect (hypothesis). $\Lambda$ close to 0 indicates the factor explains almost all the variance (strong effect); $\Lambda$ close to 1 indicates the factor explains almost nothing (no effect) — the opposite of the intuition behind conventional ANOVA's $R^2$, which tends to confuse people seeing Wilks' lambda for the first time.

### Worked example: all three methods on a single process data set

```py-r
--- python
import numpy as np
import pandas as pd
from sklearn.decomposition import FactorAnalysis
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.model_selection import train_test_split
from statsmodels.multivariate.manova import MANOVA

rng = np.random.default_rng(2026)
n = 240

# Two latent physical factors: process temperature and tool wear
temp_proc = rng.normal(0, 1, n)
desgaste  = rng.normal(0, 1, n)

# Eight surface-quality measurements: the first 4 dominated by temperature,
# the last 4 dominated by wear -- two physically distinct latent causes
cols = {}
for i in range(8):
    if i < 4:
        w_t, w_d = rng.uniform(0.75, 0.95), rng.uniform(0.05, 0.25)
    else:
        w_t, w_d = rng.uniform(0.05, 0.25), rng.uniform(0.75, 0.95)
    cols[f"measure_{i+1}"] = w_t*temp_proc + w_d*desgaste + rng.normal(0, 0.35, n)
X = pd.DataFrame(cols)

# --- 1) Factor analysis (with varimax rotation, for simple, interpretable structure) ---
fa = FactorAnalysis(n_components=2, random_state=0, rotation="varimax").fit(X)
cargas = pd.DataFrame(fa.components_.T, index=X.columns,
                       columns=["Factor 1", "Factor 2"]).round(2)
print("STEP 1 -- Factor analysis (loadings):")
print(cargas)
print("Reading: measures with a high loading on the same factor share the same latent cause.\n")

# --- 2) Discriminant analysis: predict pass/fail from the measurements ---
score = 3*temp_proc - 2*desgaste + rng.normal(0, 1.5, n)
aprovado = (score > np.median(score)).astype(int)
Xtr, Xte, ytr, yte = train_test_split(X, aprovado, test_size=0.3, random_state=0)
lda = LinearDiscriminantAnalysis().fit(Xtr, ytr)
acc = lda.score(Xte, yte)
print(f"STEP 2 -- Discriminant analysis: pass/fail classification accuracy = {acc:.1%}\n")

# --- 3) MANOVA: does one categorical factor (shift) affect 3 responses at once? ---
turno = rng.choice(["A", "B", "C"], size=n)
efeito_turno = pd.Series(turno).map({"A": 0.0, "B": 0.35, "C": -0.20}).values
dureza      = 60 + 2*temp_proc + efeito_turno*3 + rng.normal(0, 1.5, n)
rugosidade  = 1.2 + 0.3*desgaste + efeito_turno*0.4 + rng.normal(0, 0.2, n)
resistencia = 400 + 5*temp_proc - 3*desgaste + efeito_turno*6 + rng.normal(0, 8, n)

df = pd.DataFrame({"shift": turno, "hardness": dureza,
                    "roughness": rugosidade, "strength": resistencia})
maov = MANOVA.from_formula("hardness + roughness + strength ~ shift", data=df)
res = maov.mv_test()
print("STEP 3 -- MANOVA: shift effect on (hardness, roughness, strength):")
print(res)
```

**Engineering reading.** In Step 1, the factor loadings should cleanly split the eight measures into two groups, revealing that — despite there being eight numbers on the inspection sheet — there are only two independent physical causes behind them; investing in reducing the variability of "process temperature" and "tool wear" fixes all eight measures at once, instead of chasing each one in isolation. In Step 3, a small $p$-value attached to Wilks' lambda confirms the shift affects the set of three responses jointly — even if, tested in isolation, one of the three responses didn't show a statistically significant shift effect.

### Tools: Excel, Power BI, and Minitab

**Excel 365.** The Analysis ToolPak doesn't include factor analysis, discriminant analysis, or MANOVA — these are matrix-based methods beyond what a plain spreadsheet handles well. Excel serves, at most, for organizing and cleaning the input data before taking it to Python, R, or Minitab.

**Power BI (DAX).** Likewise, not a calculation tool for these three techniques; Power BI's role here is downstream — visualizing already-calculated results (for example, a scatter plot of the first two factors, colored by the class predicted by discriminant analysis) for consumption by people who don't run the model directly.

**Minitab** (current version — check minitab.com): the most complete commercial tool for the three techniques in this chapter. **Stat → Multivariate → Factor Analysis** fits the factor model and shows the rotated loadings; **Stat → Multivariate → Discriminant Analysis** builds the classification rule and reports the cross-validated classification error rate; **Stat → ANOVA → General MANOVA** runs the multivariate test and reports Wilks' lambda together with the other three classic criteria (Pillai's trace, Hotelling-Lawley trace, and Roy's largest root), useful when the different criteria's results diverge in small or unbalanced samples.

### Common mistakes

1. **Using PCA when the real goal is factor analysis.** If the question is "what latent causes explain these correlated symptoms?", PCA answers a slightly different question (total-variance reduction, without separating signal from variable-specific noise).
2. **Running several ANOVAs instead of one MANOVA when the responses are correlated.** Besides inflating the type I error rate, it ignores real information about how the responses move together.
3. **Interpreting Wilks' lambda as an R².** It's the opposite: low values indicate a strong effect, values near 1 indicate a weak effect.
4. **Applying LDA without checking the groups' linear separability.** When groups aren't linearly separable in the original variables, LDA performs poorly; nonlinear classification methods are more appropriate in those cases.
5. **Skipping out-of-sample validation in discriminant analysis.** A classification rule fit and evaluated on the same data tends to look better than it really is — always split training and test data, as in the example above.
