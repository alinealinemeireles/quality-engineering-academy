## Chapter 68: Choosing the Right Control Chart
### The engineering question

*What type of data do I have, what type of change do I want to detect, and what assumptions am I willing to make?*

Choosing the chart isn't a matter of style preference. Each chart is a **sequential hypothesis test** with its own assumptions, and using the wrong one produces either false alarms or systematic blindness.

### The decision tree

```
What type of data?
│
├── CONTINUOUS (variables)
│   │
│   ├── n = 1 (individual measurement, slow or destructive process)
│   │   └── I-MR  (Individuals and Moving Range)
│   │       ⚠ sensitive to non-normality; check the distribution
│   │
│   ├── 2 ≤ n ≤ 8  (small subgroups)
│   │   └── X̄-R   (the range is efficient and simple for small n)
│   │
│   └── n > 8  (large subgroups)
│       └── X̄-s   (the standard deviation uses all the information; R loses efficiency)
│
└── DISCRETE (attributes)
    │
    ├── Counting defective UNITS (good/bad part)
    │   ├── constant n  → np
    │   └── variable n  → p
    │       Assumption: BINOMIAL (independent units, constant p)
    │
    └── Counting DEFECTS (a part can have several)
        ├── constant area/opportunity → c
        └── variable area/opportunity → u
            Assumption: POISSON (independent defects, constant rate)
```

**Cases the tree doesn't cover — and that always come up in practice:**

| Situation | Suitable chart | Chapter |
|---|---|---|
| Detecting small shifts (< 1.5σ) quickly | EWMA or CUSUM | next |
| Small lots, many part numbers | Z-MR, DNOM (short-run) | next |
| Autocorrelated data (continuous processes) | ARIMA model residuals chart | next |
| Rare events (very infrequent defects) | g and t charts (time/units between events) | next |
| Overdispersion in count data | Laney charts (p′, u′) | next |

### The detection rules (Nelson / Western Electric)

A point outside the limits is just the first test. The supplementary rules detect patterns the limits alone don't catch:

| # | Rule (Nelson) | What it suggests |
|---|---|---|
| 1 | 1 point beyond 3σ | Big shift, measurement error, one-off event |
| 2 | 9 consecutive points on the same side of the center line | **Level shift** |
| 3 | 6 consecutive points trending up or down | **Drift** (wear, temperature) |
| 4 | 14 points alternating up and down | Overcontrol, two alternating sources |
| 5 | 2 of 3 consecutive points beyond 2σ (same side) | Moderate shift |
| 6 | 4 of 5 consecutive points beyond 1σ (same side) | Small, sustained shift |
| 7 | 15 consecutive points within 1σ | **Stratification** — subgroup too wide, or wrong limits |
| 8 | 8 consecutive points beyond 1σ (both sides) | Mixture of two populations |

**Watch the statistical cost.** Each additional rule increases the false-alarm rate. With just rule 1, the per-point false-alarm rate is ≈0.27% (ARL₀ ≈ 370). Turning on all eight rules drops ARL₀ to about 90 — that is, **a false alarm about every ~90 points** even with a perfectly stable process.

The practical recommendation: enable rules 1, 2, 3, and 5 by default. Rule 7 is worth enabling not to control the process, but to **audit the chart itself** — it catches the stratified subgroup from the previous chapter.

### Worked example: implementing the rules and comparing charts

```py-r
--- python
import numpy as np
import pandas as pd

def regras_nelson(x, cl, sigma, regras=(1,2,3,5,6,7)):
    """Aplica as regras de Nelson. Devolve dict regra -> índices sinalizados."""
    x = np.asarray(x, float); z = (x - cl) / sigma
    n = len(x); out = {}
    if 1 in regras:
        out[1] = list(np.where(np.abs(z) > 3)[0])
    if 2 in regras:
        s = np.sign(z); idx = []
        for i in range(8, n):
            w = s[i-8:i+1]
            if np.all(w > 0) or np.all(w < 0): idx.append(i)
        out[2] = idx
    if 3 in regras:
        d = np.diff(x); idx = []
        for i in range(5, len(d)):
            w = d[i-5:i+1]
            if np.all(w > 0) or np.all(w < 0): idx.append(i+1)
        out[3] = idx
    if 5 in regras:
        idx = []
        for i in range(2, n):
            w = z[i-2:i+1]
            if (np.sum(w > 2) >= 2 and z[i] > 2) or (np.sum(w < -2) >= 2 and z[i] < -2):
                idx.append(i)
        out[5] = idx
    if 6 in regras:
        idx = []
        for i in range(4, n):
            w = z[i-4:i+1]
            if (np.sum(w > 1) >= 4 and z[i] > 1) or (np.sum(w < -1) >= 4 and z[i] < -1):
                idx.append(i)
        out[6] = idx
    if 7 in regras:
        idx = [i for i in range(14, n) if np.all(np.abs(z[i-14:i+1]) < 1)]
        out[7] = idx
    return {k: v for k, v in out.items() if v}

# --- Processo com uma mudança de nível de 0,8 sigma a meio ---
rng = np.random.default_rng(11)
sigma_proc, media = 1.0, 50.0
x = np.concatenate([rng.normal(media, sigma_proc, 40),
                    rng.normal(media + 0.8*sigma_proc, sigma_proc, 40)])

# carta I-MR: sigma estimado por MR-barra/d2 (d2 = 1.128 para n=2)
MR = np.abs(np.diff(x)); sigma_hat = MR.mean() / 1.128
cl = x[:40].mean()
print(f"Linha central = {cl:.3f} | sigma estimado (MR/d2) = {sigma_hat:.3f}")
print(f"Limites 3-sigma: [{cl-3*sigma_hat:.3f} ; {cl+3*sigma_hat:.3f}]\n")

sinais = regras_nelson(x, cl, sigma_hat)
print("Sinais por regra (índice do ponto, mudança real ocorreu no ponto 40):")
for r in sorted(sinais):
    prim = min(sinais[r])
    print(f"  Regra {r}: {len(sinais[r]):>2} sinais | primeiro no ponto {prim:>2}"
          f" ({'DEPOIS' if prim >= 40 else 'antes'} da mudança)")

so_regra1 = regras_nelson(x, cl, sigma_hat, regras=(1,))
print(f"\nCom APENAS a regra 1: {len(so_regra1.get(1, []))} sinais.")
print("=> Uma mudança de 0,8 sigma é praticamente invisível para os limites 3-sigma.")
print("   É exatamente para este regime que existem a EWMA e a CUSUM (capítulo seguinte).")
```

### When the attribute chart fails: overdispersion

$p$, $np$, $c$, and $u$ charts assume binomial or Poisson. In these distributions, variance is a **function determined by the mean** — it isn't a free parameter. When the real variation exceeds what's predicted (from different raw-material lots, for example), the chart shows out-of-control points constantly and the team gives up on it.

**How to diagnose it.** Compare the observed variation against what the model expects. A practical test is the Laney dispersion statistic.

```py-r
--- python
import numpy as np
from scipy import stats

rng = np.random.default_rng(5)
n_lotes, n_por_lote = 30, 400
p_medio = 0.04

# Cenário 1: binomial pura       Cenário 2: p varia entre lotes (sobredispersão)
d_puro  = rng.binomial(n_por_lote, p_medio, n_lotes)
p_var   = rng.beta(4, 4*(1-p_medio)/p_medio, n_lotes)   # p aleatório em torno de 0,04
d_sobre = rng.binomial(n_por_lote, p_var)

def diagnostico(defeituosas, n, rotulo):
    p_hat = defeituosas / n
    pbar = defeituosas.sum() / (n * len(defeituosas))
    sigma_binom = np.sqrt(pbar * (1 - pbar) / n)
    z = (p_hat - pbar) / sigma_binom
    sigma_z = z.std(ddof=1)          # estatística de Laney: ~1 se binomial for adequada
    lsc, lic = pbar + 3*sigma_binom, max(0, pbar - 3*sigma_binom)
    fora = int(((p_hat > lsc) | (p_hat < lic)).sum())
    # teste qui-quadrado de homogeneidade da proporção entre lotes
    chi2 = (((defeituosas - n*pbar)**2) / (n*pbar*(1-pbar))).sum()
    pval = 1 - stats.chi2.cdf(chi2, len(defeituosas)-1)
    print(f"{rotulo}")
    print(f"   p-barra = {pbar:.4f} | sigma_z (Laney) = {sigma_z:.2f} "
          f"| pontos fora numa carta p = {fora}/{len(defeituosas)}")
    print(f"   Teste de homogeneidade: chi2 = {chi2:.1f}, p-value = {pval:.4g}")
    if sigma_z > 1.2:
        print(f"   => SOBREDISPERSÃO. Usar carta p' de Laney "
              f"(limites {sigma_z:.2f}x mais largos) ou modelo binomial-beta.\n")
    else:
        print("   => Binomial adequada. Carta p convencional serve.\n")

diagnostico(d_puro,  n_por_lote, "Cenário 1 — proporção estável entre lotes")
diagnostico(d_sobre, n_por_lote, "Cenário 2 — proporção varia entre lotes")
```

**Engineering reading.** In scenario 2, the conventional $p$ chart flags many out-of-control points, but **there's no special cause at all to chase at each point** — there's a structural source of variation between lots that the binomial model doesn't account for.

The correct action isn't investigating each point: it's (a) recognizing lot-to-lot variation as part of the system and using the Laney chart, **or** (b) treating the lot as a factor and studying it — which is a modeling problem (logistic regression with a random lot effect, PART V), not an SPC one.

### Common mistakes

1. **Using I-MR by default.** It's the most widely used chart and the most sensitive to non-normality. With skewed data, it produces systematic false alarms on the long-tail side.
2. **Turning on all eight Nelson rules.** Triples the false-alarm rate. The team ends up ignoring the chart.
3. **A p chart on processes with overdispersion.** See above.
4. **An attribute chart when continuous measurement is available.** A $p$ chart of "parts out of tolerance" wastes the actual measurement's information and needs much larger samples for the same sensitivity. If you can measure it, measure it.
5. **X̄-R with a large n.** For $n > 8$, the range only uses two points from the subgroup and loses efficiency; use X̄-s.
