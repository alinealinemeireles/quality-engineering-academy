## Chapter 70: Short-Run SPC, Autocorrelation, and Rare Events
### The engineering question

*What about when the process looks nothing like the textbook example?*

Three very common situations in real industry break classic SPC's assumptions. Each has a solution — and ignoring them is why many SPC implementations die within six months.

### Situation 1 — Short runs and high mix

The case: a shop producing 40 different part numbers in lots of 15 to 60 pieces. No part number generates enough data to establish its own control limits.

**The solution: normalize and use a single chart.**

**DNOM chart (deviation from nominal)** — when variability is similar across part numbers:

$$x_i^* = x_i - \text{Nominal}_{\text{part}}$$

Every part number feeds the same chart, measured as deviation from nominal.

**Z-MR chart (standardized)** — when variability differs across part numbers:

$$Z_i = \frac{x_i - \bar{x}_{\text{part}}}{\hat{\sigma}_{\text{part}}}$$

Here, the chart always has a center line of 0 and limits of ±3, regardless of part number. The price: you need a prior estimate of $\bar{x}$ and $\hat{\sigma}$ per part number (from history or an initial study).

**Critical assumption:** that the part numbers share the **same common-cause system**. An aluminum part and a steel part on the same machine might not. Check before grouping — with a variance-homogeneity test.

```py-r
--- python
import numpy as np
import pandas as pd
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)

# Oficina com 5 referências, lotes curtos, nominais e sigmas diferentes
refs = pd.DataFrame({
    "Ref":     ["A", "B", "C", "D", "E"],
    "Nominal": [12.00, 25.00, 8.50, 40.00, 18.00],
    "Sigma":   [0.030, 0.045, 0.022, 0.055, 0.031],
    "N":       [18, 22, 15, 20, 25],
})

linhas = []
for _, r in refs.iterrows():
    vals = rng.normal(r["Nominal"], r["Sigma"], int(r["N"]))
    if r["Ref"] == "D":                       # introduzir causa especial na ref D
        vals[-6:] += 2.5 * r["Sigma"]
    for v in vals:
        linhas.append({"Ref": r["Ref"], "Valor": v,
                       "Nominal": r["Nominal"], "Sigma_ref": r["Sigma"]})
d = pd.DataFrame(linhas)

# Verificação do pressuposto: as variâncias são homogéneas entre referências?
grupos = [g["Valor"].values - g["Nominal"].iloc[0] for _, g in d.groupby("Ref")]
W, p = stats.levene(*grupos, center="median")
print(f"Teste de Levene à homogeneidade de variâncias entre referências:")
print(f"   W = {W:.3f}, p-value = {p:.4f}")
print(f"   => {'variâncias diferentes -> usar Z-MR' if p < 0.05 else 'variâncias compatíveis -> DNOM serve'}\n")

# Carta DNOM
d["DNOM"] = d["Valor"] - d["Nominal"]
mr = np.abs(np.diff(d["DNOM"])); s_dnom = mr.mean()/1.128
cl_d = d["DNOM"].mean()
fora_dnom = int((np.abs(d["DNOM"] - cl_d) > 3*s_dnom).sum())

# Carta Z (padronizada por referência)
d["Z"] = (d["Valor"] - d["Nominal"]) / d["Sigma_ref"]
fora_z = int((np.abs(d["Z"]) > 3).sum())

print(f"Carta DNOM : sigma comum = {s_dnom:.4f} | pontos fora = {fora_dnom}")
print(f"Carta Z    : limites fixos ±3        | pontos fora = {fora_z}")
print(f"\nPontos sinalizados pela carta Z:")
print(d[np.abs(d['Z']) > 3][["Ref", "Valor", "Z"]].round(3).to_string(index=False))

fig, axes = plt.subplots(2, 1, figsize=(11, 6), sharex=True)
cores = {r: c for r, c in zip(refs["Ref"], ["#00688f","#31803a","#6a3d9a","#d17a00","#a5203a"])}
cs = d["Ref"].map(cores)
axes[0].scatter(range(len(d)), d["DNOM"], c=cs, s=18)
axes[0].axhline(cl_d+3*s_dnom, color="r", ls="--"); axes[0].axhline(cl_d-3*s_dnom, color="r", ls="--")
axes[0].set_title("Carta DNOM — desvio ao nominal (sigma comum)")
axes[1].scatter(range(len(d)), d["Z"], c=cs, s=18)
axes[1].axhline(3, color="r", ls="--"); axes[1].axhline(-3, color="r", ls="--")
axes[1].axhline(0, color="g"); axes[1].set_title("Carta Z — padronizada por referência")
axes[1].set_xlabel("sequência de produção (cores = referências)")
plt.tight_layout(); plt.show()
```

**Engineering reading.** With heterogeneous variances, DNOM dilutes: it uses a common sigma, which is too wide for the precise part numbers and too tight for the coarse ones. The Z chart, by standardizing per part number, detects the special cause introduced at part D — which DNOM might let slip through.

The Levene test isn't a formality: it's what decides which of the two charts is legitimate.

### Situation 2 — Autocorrelation

The case: continuous processes (chemistry, temperature, film thickness, tank level) measured at high frequency. Observations close together in time are similar by physical nature, not by special cause.

**The effect on the chart.** Positive autocorrelation makes $\overline{MR}$ drastically underestimate the true sigma, the limits tighten, and the chart produces **cascading false alarms**. This is the typical pattern of "the chart is always beeping and no one finds any cause."

**The solution: model and control the residuals.**

1. Fit a time-series model (AR(1) is often enough; ARIMA if needed).
2. Calculate the residuals $e_t = x_t - \hat{x}_t$.
3. Apply the control chart **to the residuals**, which are approximately independent.

This is called a *residuals chart* or **model-based SPC**. The model captures the predictable dynamics; the chart looks for what the model doesn't explain.

```py-r
--- python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import acf

rng = np.random.default_rng(9)
n, phi, sigma_e, mu = 200, 0.80, 1.0, 50.0

# Processo AR(1) com um degrau real de +3 unidades a partir de t=150
x = np.zeros(n); x[0] = mu
for t in range(1, n):
    x[t] = mu + phi*(x[t-1] - mu) + rng.normal(0, sigma_e)
x[150:] += 3.0

r1 = acf(x, nlags=1, fft=False)[1]
print(f"Autocorrelação lag-1 dos dados brutos: {r1:.3f}")
print("(acima de ~0,3 a carta de Shewhart convencional deixa de ser válida)\n")

# --- Carta I-MR ingénua sobre os dados brutos ---
MR = np.abs(np.diff(x)); s_mr = MR.mean()/1.128
cl = x[:150].mean()
fora_bruto = np.where(np.abs(x - cl) > 3*s_mr)[0]
print(f"Carta I-MR sobre dados brutos:")
print(f"   sigma estimado por MR/d2 = {s_mr:.3f}  |  sigma real do processo = "
      f"{sigma_e/np.sqrt(1-phi**2):.3f}")
print(f"   => subestima o sigma em {1 - s_mr/(sigma_e/np.sqrt(1-phi**2)):.0%}")
print(f"   Pontos fora ANTES do degrau real (falsos alarmes): "
      f"{int((fora_bruto < 150).sum())}")
print(f"   Pontos fora depois do degrau: {int((fora_bruto >= 150).sum())}\n")

# --- Carta de resíduos de um AR(1) ---
modelo = ARIMA(x[:150], order=(1, 0, 0)).fit()
print(f"Modelo AR(1) ajustado à fase estável: phi = {modelo.arparams[0]:.3f} "
      f"(real {phi})")
pred = modelo.apply(x, refit=False).predict()
resid = x - pred
resid_estavel = resid[1:150]
s_res = np.abs(np.diff(resid_estavel)).mean()/1.128
cl_r = resid_estavel.mean()
fora_res = np.where(np.abs(resid - cl_r) > 3*s_res)[0]
fora_res = fora_res[fora_res > 0]
print(f"\nCarta sobre os RESÍDUOS do AR(1):")
print(f"   ACF lag-1 dos resíduos = {acf(resid_estavel, nlags=1, fft=False)[1]:.3f} (≈0 é o objetivo)")
print(f"   Falsos alarmes antes do degrau: {int((fora_res < 150).sum())}")
primeiro = fora_res[fora_res >= 150]
print(f"   Primeiro sinal após o degrau: ponto {primeiro[0] if len(primeiro) else 'nenhum'} "
      f"(degrau em 150 -> atraso de {primeiro[0]-150 if len(primeiro) else '-'} pontos)")

fig, axes = plt.subplots(2, 1, figsize=(11, 6), sharex=True)
axes[0].plot(x, lw=0.9, color="#00688f")
axes[0].axhline(cl+3*s_mr, color="r", ls="--"); axes[0].axhline(cl-3*s_mr, color="r", ls="--")
axes[0].plot(fora_bruto, x[fora_bruto], "ro", ms=4)
axes[0].axvline(150, color="k", ls=":"); axes[0].set_title(
    "Dados brutos autocorrelacionados — limites apertados demais, falsos alarmes")
axes[1].plot(resid, lw=0.9, color="#31803a")
axes[1].axhline(cl_r+3*s_res, color="r", ls="--"); axes[1].axhline(cl_r-3*s_res, color="r", ls="--")
axes[1].plot(fora_res, resid[fora_res], "ro", ms=4)
axes[1].axvline(150, color="k", ls=":"); axes[1].set_title(
    "Resíduos do modelo AR(1) — o sinal real destaca-se")
plt.tight_layout(); plt.show()
```

### Situation 3 — Rare events

The case: high-quality processes where a defect occurs once every 20,000 units. A $p$ or $u$ chart is useless — almost every subgroup has zero defects, the lower limit is zero, and the chart detects no improvement at all.

**The solution: change the variable.** Instead of counting defects per period, count **units or time between consecutive defects**.

- **g chart** — number of units between events (geometric distribution).
- **t chart** — time between events (exponential distribution, often transformed via Weibull).

Additional advantage: when the process improves, the time between events **increases**, and the t chart detects the improvement — something a u chart, with counts almost always at zero, would never do.

```py-r
--- python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

rng = np.random.default_rng(15)

taxa_antes  = 1/1500      # 1 evento por 1500 unidades
taxa_depois = 1/4200      # melhoria: 1 por 4200 unidades

g_antes  = rng.geometric(taxa_antes, 40)
g_depois = rng.geometric(taxa_depois, 25)
g = np.concatenate([g_antes, g_depois])

# --- Abordagem ERRADA: carta u com subgrupos de 1000 unidades ---
tam_sub = 1000
posicoes = np.cumsum(g)
n_sub = int(posicoes[-1] // tam_sub)
contagens = np.array([((posicoes > i*tam_sub) & (posicoes <= (i+1)*tam_sub)).sum()
                      for i in range(n_sub)])
ubar = contagens.mean()
print("Abordagem 1 — carta u (contagens por 1000 unidades):")
print(f"   u-barra = {ubar:.3f} defeitos/1000 un")
print(f"   Subgrupos com ZERO defeitos: {(contagens==0).sum()}/{n_sub} "
      f"({(contagens==0).mean():.0%})")
print(f"   LSC = {ubar + 3*np.sqrt(ubar/1):.2f} | LIC = "
      f"{max(0, ubar - 3*np.sqrt(ubar/1)):.2f} (colado a zero -> não deteta melhoria)\n")

# --- Abordagem CORRETA: carta g (unidades entre eventos) ---
# Para a geométrica usa-se transformação para aproximar a normalidade
gbar_fase1 = g_antes.mean()
sigma_g = np.sqrt(gbar_fase1*(gbar_fase1-1))
lsc_g = gbar_fase1 + 3*sigma_g; lic_g = max(0, gbar_fase1 - 3*sigma_g)
print("Abordagem 2 — carta g (unidades entre eventos consecutivos):")
print(f"   Linha central (fase 1) = {gbar_fase1:.0f} unidades entre eventos")
print(f"   LSC = {lsc_g:.0f} | LIC = {lic_g:.0f}")
sinais = np.where(g > lsc_g)[0]
print(f"   Pontos acima do LSC: {list(sinais)}  (mudança real ocorre no evento 40)")
print(f"   => valores ACIMA do LSC indicam MELHORIA do processo\n")

# Teste formal de que a taxa mudou
from scipy.stats import mannwhitneyu
U, p = mannwhitneyu(g_antes, g_depois, alternative="less")
print(f"Teste de Mann-Whitney (H1: intervalos maiores depois): p = {p:.5f}")
print(f"   Média antes = {g_antes.mean():.0f} un | depois = {g_depois.mean():.0f} un")

fig, ax = plt.subplots(figsize=(11, 3.5))
ax.plot(g, "o-", ms=4, lw=0.8, color="#00688f")
ax.axhline(gbar_fase1, color="g"); ax.axhline(lsc_g, color="r", ls="--")
ax.axvline(40, color="k", ls=":")
ax.plot(sinais, g[sinais], "go", ms=8)
ax.set_ylabel("unidades entre eventos"); ax.set_xlabel("nº do evento")
ax.set_title("Carta g — eventos raros. Pontos acima do LSC = melhoria detetada")
plt.tight_layout(); plt.show()
```

### Common mistakes

1. **Applying classic SPC to continuous processes without checking for autocorrelation.** Always calculate the lag-1 ACF before drawing the first chart. Above ~0.3, the conventional limits aren't valid.
2. **Fixing autocorrelation by sampling less frequently.** It works (correlation decays with the interval), but wastes information and delays detection. Modeling is better.
3. **A Z chart without solid prior per-part-number estimates.** With 6 pieces of history, a part number's $\hat{\sigma}$ is so unstable that standardizing adds noise instead of removing it.
4. **Mixing part numbers with different physical processes on the same short-run chart.** Test for homogeneity first.
5. **Insisting on attribute charts for rare events.** If more than 25% of subgroups show zero counts, switch to g or t charts.
